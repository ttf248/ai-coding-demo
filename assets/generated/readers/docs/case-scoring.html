案例截图评分规则

评分目的与边界

评分只衡量归档截图中可见的任务成果与呈现质量，服务于本站首页浏览排序。它不代表源码正确性、交互实际可用性、性能、模型能力或跨任务公平比较。截图没有展示的功能不得推定为已完成；明显显示的错误状态、空画布、裁切或低对比应按可见证据扣分。

先阅读该实验关联的 prompt.md，再按原始 PNG 的完整分辨率检查截图。不能只凭模型、档位、费用、日期、主题复杂度或预览代码加减分。不同窗口大小和截图取景会影响截图分；这是案例目录用途的视觉索引，不是基准测试。

维度与分值

每项使用整数分，合计 100 分。不可把同一问题在多个维度重复扣分；每条评分的 evidence 写明截图中支持分数的内容和主要缺口。

维度 满分 判断内容
任务可见覆盖 30 截图能否看到提示词要求的主要对象、核心信息区和关键状态。仅画布或空壳按可见缺失扣分；不可据截图猜测隐藏功能。
构图与层级 25 主体是否突出，页面区域、留白、对齐、密度和视线顺序是否清楚。
可读性与对比 20 文字、图例、状态和控件在截图尺寸下是否可辨，前景与背景对比是否足够。
操作线索 15 截图可见的控件是否容易理解和定位，提示、状态反馈及操作入口是否对应主要内容。只评价视觉线索，不验证控件是否真的可用。
完成度与一致性 10 字体、色彩、间距、图标、组件风格是否一致；是否有占位、断裂、遮挡、错位或明显未完成区域。

评分锚点按每项满分比例使用：

  • 90%–100%：要求基本完整，表现清楚且稳定；只剩轻微问题。
  • 75%–89%：主要结果完整可读，有一两处布局、密度或细节问题。
  • 50%–74%：核心对象可辨，但有明显缺项、弱层级、留白失衡或信息不足。
  • 1%–49%：只有局部结果或界面线索；空白、错误状态、严重裁切或不可读内容占主导。
  • 0 分：该维度完全没有可见证据。

锚点是分值范围，不是将总分换算成每项分数的公式。每项须独立判断，并保留具体整数分。

记录格式与状态

每个 run.json 都有 score：

{
  "rubricVersion": 1,
  "status": "rated",
  "total": 95,
  "dimensions": {
    "taskCoverage": 29,
    "composition": 24,
    "readability": 19,
    "interactionClarity": 14,
    "craft": 9
  },
  "assessedAt": "2026-10-15",
  "screenshotHash": "该截图 PNG 的 SHA-256",
  "evidence": "截图中的塔楼群、城市平台和漫游控制完整可见，主次明确；小号状态文字略弱。"
}

五项分数之和必须等于 total。screenshotHash 必须匹配截图文件的 SHA-256；截图替换后校验会要求重新评估。日期记录本次复核日期。证据应写截图中可核对的对象及主要优缺点，避免只写“优秀”“美观”等结论。

  • rated：有真实案例截图并完成五项评分。
  • unavailable：记录没有可评分的真实截图。total、dimensions、screenshotHash 必须为 null，证据说明缺少截图的原因；不把无证据当作 0 分，也不进入排序。
  • pending：只允许没有截图且 preview.kind 为 none 的草稿。补入截图或将记录标为 ready 前必须完成评分；校验会拒绝其他待评分记录。

不要把主题缩略图、占位图或验收报告封面当作实验截图。确认入口可运行时依项目维护规则补拍实际桌面截图，再评分。

首页排序与并列规则

首页默认按任务复杂度从高到低排列主题。每张主题卡片独立选择当前筛选范围内评分最高的已评分实验，显示该实验的评分、截图和可用预览；主题顺序不受实验评分影响。截图不可用时才按项目原有缩略图回退规则显示；无截图记录排在已评分记录之后。

复杂度相同时按当前筛选范围内最新实验日期从新到旧，再按主题 ID 升序，保证不同机器得到相同顺序。用户仍可切换评分、最新记录或名称排序。首页默认的“参与测试”范围不包含已归档主题；切换“全部案例”后，复杂度顺序和每个主题的最高分记录都对该范围重新计算。

长期维护

新建实验脚手架写入 pending；每张真实截图都必须完成评分才能通过校验。只改文档不需重评；截图内容改变必须重评并更新 hash。修正错评时保留原截图，在同一 run.json 中更新各维度、总分、复核日期、hash 和证据。

若评分维度或锚点改变，递增 rubricVersion，更新本文件和 catalog/schema.json，逐条重评所有有截图的实验；不把新规则直接套到旧分数上。重新评分须在变更说明记录范围和原因。缺失截图仍保持 unavailable，除非之后补入真实截图。
