模型排序与官方资料核对表

排序依据保存在 模型字典，筛选列表、主题页实验记录、按模型视图、档位矩阵及对比候选共用同一个排序函数。

  1. 厂商分组保持现有顺序，厂商内部先按显式登记的代际从新到旧，再按同代能力层级从高到低，最后按发布日期从新到旧。
  2. 代际由 generation 显式登记，不从显示名称解析。GPT-6.1 Sol 与 GPT-6 Astra / Sol / Luna 同属 GPT-6 代；Claude Opus / Sonnet / Haiku 5.5 同属 5.5 代。因此较晚发布的 Haiku 5.5 不会排在同代 Opus / Sonnet 前。能力优先级依据已保存的官方产品定位与比较作维护判断，不是跨代或跨厂商分数。
  3. 日期缺失的型号置于该厂商末尾；同代能力缺失的型号置于能力已登记型号之后。其余并列保留版本、变体及 ID 的稳定顺序，不据此宣称能力强弱。
  4. Free 等接入标签按可识别的基础模型首发排序，不将平台免费开放日期、文档修改、区域上线或正式版日期套用为历史检查点的首发日期。

npm run models:pending 仅列出缺少查证记录的新型号和已查过的待确认项，不联网。已有记录直接复用，包括明确登记的未知；仅新型号缺少记录或维护者明确要求重新查证时才查询官方消息。
