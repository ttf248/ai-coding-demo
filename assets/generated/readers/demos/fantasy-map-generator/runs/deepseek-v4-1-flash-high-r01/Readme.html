奇幻地图生成器（DeepSeek-V4.1-Flash · high · r01）

单文件静态网页，直接打开 index.html 即可运行。无后端、无 CDN、无远程字体或图片、无构建步骤，file:// 与 HTTP 静态托管都能运行。

原始提示词

见 完整原始输入；任务正文与 v1 任务正文 逐字一致。

实现要点

  • 高度场 = 多倍频值噪声 × 岛屿衰减掩膜。噪声查找表、山脊细节、海岸抖动全部由 seed 派生（FNV-1a 把种子文本散列为 32 位），因此种子与参数一致时地图逐像素一致。
  • 地形分类：海洋（按深度分色）、近岸浅海、海岸、平原、森林、山脉。森林由第二张湿度噪声决定，山脉由高出海平面的幅度决定。
  • 河流：从高处候选源点出发，每一步只走向八邻域中最低的一格。这是最陡下降法，不会上坡；山脉定义在高出海平面 0.30 以上，而允许的累计爬升预算只有 0.028，因此河流在数值上不可能翻越山脊。到达洼地则汇成内陆小湖，汇入已有河流也会停止。
  • 画笔：升高 / 降低直接修改高度场，松手后重算河流与城镇并重绘，海岸线随之变化。
  • 视图：滚轮以光标为锚点缩放，捏合手势以捏合起点为基准换算（避免逐帧漂移），平移工具用 Pointer Events，坐标经逆变换换算，缩放后落笔位置仍准确。
  • 导出：合成一张带双线边框、标题与参数说明的 PNG，含当前地图；使用 toDataURL + 下载链接，file:// 下同样可用。

运行与复盘

  • 运行方式：浏览器直接打开本目录 index.html；或使用根目录 npm run preview 后的静态托管地址。
  • 未使用网络资源，断网可用。
  • 复盘：核心算法一次成立（确定性、河流不翻山脊、画笔联动）。首轮生成后做了两轮自查调整：一是初始陆地占比仅 23.5%，岛体偏小，调整掩膜阈值与高度基准后稳定在 30%~41%（随种子浮动，海平面滑块可覆盖 28.7%~47.6%）；二是森林阈值过高导致森林几乎不出现、河流线宽过细不易辨认，已下调阈值并加粗河流，同时加入逐格色差减轻方块感。两处均为参数与呈现层面的调整，未改动算法结构，changes 为空。
