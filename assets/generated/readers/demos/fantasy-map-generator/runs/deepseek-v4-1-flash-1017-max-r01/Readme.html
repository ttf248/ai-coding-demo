奇幻地图生成器

原始输入

  • 完整原始输入：prompt.md
  • 任务正文版本：v1。

实现说明

  • 单文件离线页面，入口 index.html。
  • 高度场：种子哈希 + 多八度 value noise + 域扭曲 + 岛形遮罩；海平面、粗糙度可调。
  • 地形分类：深海/浅海、海岸、平原、森林、山地、雪顶；湿度噪声决定森林，坡度光照形成明暗。
  • 水文：priority-flood 洼地填充保证水流有出口，最陡下降生成河网；河网以流量阈值筛选，湖泊按填充深度标记；河流不会随机翻越山峰。
  • 渲染：Canvas 2D 低分辨率高度场放大 + 手绘海岸/等高线（marching squares）+ 纸张纹理 + 山脉/森林符号 + 城镇标签 + 标题饰框、指北针、比例尺、图例与边框。
  • 编辑与交互：平移/缩放/双指捏合、升高/降低画笔、笔刷半径、城镇显示开关、随机种子、导出整幅 PNG。
  • 缩放使用统一相机变换，绘制与指针拾取都通过世界/屏幕逆变换，缩放后坐标保持一致。

验证记录

  • Playwright 检查：
    • 相同种子重新生成签名一致；更换种子签名不同。
    • screenToWorld(500,300) 后再 worldToScreen 回到 (500,300)。
    • 拖动画笔后指定区域高度和签名发生变化，海岸/河流随之重算。
    • 390px 无页面水平溢出。
  • 默认地图陆地约 36%，默认河网采样格约 2146；界面将统计标为“河网采样格”，避免把高度场采样数误解为连续河流条数。

复盘

  • 河流密度阈值从 18 调到 60，减少细碎支流，使主河道和流域更清晰；湖泊来自洼地填充。
  • 画笔采用节流重建，拖动过程中会周期性更新；笔画结束后立即重算。
  • 导出的是整幅 1600×1120 地图层，不是当前视口，包含标题、图例与城镇标签。
