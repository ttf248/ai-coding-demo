原始提示词

见 完整原始输入。本轮输入与主题提示词 v1 完全一致，未做改写或裁剪。

实现说明

  • 地形由带种子的梯度噪声叠加径向岛屿掩膜生成；同一种子与参数结果完全一致（浏览器自动化比对画布像素哈希验证）。
  • 河流先用优先队列做洼地填充，再沿填充高度严格下降回溯到海洋，并偏好延续原方向形成自然弯曲。
  • 画笔升高/降低地形后立即重算海岸线，河流在停止编辑 220ms 后重算；城镇标签按屏幕尺寸缩放保持可读。

运行方式

纯静态单文件：直接用浏览器打开本目录入口即可运行，不依赖任何外部资源。

复盘

  • 优点：河流顺着填洼后的高程严格下降，避免了穿山；同种子结果完全一致，适合做参数化美术工具。

  • 不足：地图尺寸固定为 220×150 格，放大到 14 倍后单个格子边缘略显锯齿；河流在极端地形下仍可能出现一次“漫过”高地。
