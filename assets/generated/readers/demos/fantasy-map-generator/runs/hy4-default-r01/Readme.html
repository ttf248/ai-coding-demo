奇幻岛屿地图生成器

原始提示词

见 完整原始输入。

运行与复盘

入口：index.html。单文件、纯离线，可直接以 file:// 打开，无 CDN、无远程图片与字体、无构建步骤。

运行方式：输入种子、调整海平面与粗糙度后生成地图；用画笔直接在画布上抬高/压低地形；支持缩放、平移、城镇标签开关与 PNG 导出。

实现要点：以种子驱动的确定性多层值噪声叠加岛屿衰减生成高程；水文用 priority-flood 填洼、最陡下降坡度方向与 flow accumulation 计算河流，河流最终注入海洋或内陆水体；画笔修改高程后标记河流脏位，笔触结束时重新计算海岸线与河网，保证地形与河流一致；全部绘制走 Canvas 2D 画笔。

验证记录：同种子重复生成结果一致；修改地形后海岸与河流同步更新；PNG 导出可用；内联脚本 node --check 语法检查通过。

已知限制：为栅格高程 + 程序化河流，未实现生物群系分类、道路网与地名语言学生成；大尺寸画布重算水文有明显开销。
