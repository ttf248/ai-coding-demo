手绘风奇幻岛屿地图生成器（Qwen3.8 Max · xhigh）

原始提示词

见 完整原始输入，任务正文版本 v1。

批次记录

Aliyun 批次合计 91.81 CNY，覆盖 11 个案例，耗时 2h 50m 7s；费用及耗时均为批次总计，不拆分为单案例。

运行方式

  • 入口为本目录 index.html，file:// 直接打开或 HTTP 静态托管均可，无外部依赖。
  • 种子 + 海平面 + 粗糙度决定地形；「重新生成」按当前种子重建，「随机种子」换种子。
  • 工具：平移 / 升高地形 / 降低地形（笔刷半径与强度可调）；滚轮或双指捏合缩放，缩放后画笔仍落在指针世界坐标；「城镇标签」开关；「导出 PNG」保存当前视图。

验证记录

2026-10-14 Playwright（Chromium headless）冒烟测试，file:// 与 HTTP 双入口：

  • 同种子两次「重新生成」画布逐像素一致；改变种子得到不同地图。
  • 海平面滑块改变水陆分布；默认地图存在河流（状态栏统计 180 段）与内陆湖。
  • 滚轮缩放后在指定屏幕点抬升地形，该点像素变化，证明缩放后绘制坐标正确。
  • 平移工具移动视图；城镇标签开关改变渲染；导出 PNG 有合法签名、体积合理且内容非纯色。
  • 390px 无水平溢出；CDP 触摸事件单指绘制地形生效、双指捏合改变缩放比例。
  • 桌面与移动端均无 JS 报错。

复盘

  • 水文第一版用最陡下降，结果默认种子整座岛是一个大洼地，全部汇流陷在内陆局部极小值、零条河流入海；改为 priority-flood 填洼：从海洋做优先级泛洪，每格获得指向海方向的 cameFrom 指针，填洼面与原始地形之差即内陆湖，河流沿 cameFrom 链绘制——在原始地表上只往低处走，不会穿越山峰，汇入海洋或内陆湖后停止。
  • 填洼得到的洼地含大量 1～2 格碎斑，按连通分量过滤（≥10 格才成湖）后地图干净得多；河流线宽设下限保证可见。
  • 所有随机性（噪声置换表、墨线抖动、山脉符号、城镇选址）都由种子派生，保证「同种子重生成一致」；画布分基础水彩层与墨线层两张离屏缓存，平移缩放只重合成不重算。
  • 地形画笔直接修改高度场并触发水文与墨线重算，因此「编辑后更新海岸和河流」是结构性保证而非特判。
