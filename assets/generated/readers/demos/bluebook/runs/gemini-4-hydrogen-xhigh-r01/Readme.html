  • 技术栈：React 18 + TypeScript + Tailwind CSS + Zustand + react-lazyload + Vite。
  • 布局结构：顶部吸顶搜索栏（“小蓝书”标志、实时关键词搜索、“+ 发布”弹窗按钮与频道标签切换）；瀑布流主体自适应移动端 2 列、平板 3 列、桌面端 4 列。
