原始提示词

见 完整原始输入。

运行与验证

  • 入口：index.html，纯静态单文件（HTML/CSS/JS/SVG 内联），无后端、无 CDN、无远程资源，file:// 直接双击打开与 HTTP 静态托管均可运行。
  • 操作：上方按钮添加电池/电阻/灯泡/开关；拖动元件本体移动（连线跟随）；从端子拖出到另一端子连线（触摸设备可两次点按端子完成连线）；点选元件/导线后可在左侧面板改参数或删除（删除元件连带清除其连线）；点击开关本体切换通断。
  • 求解：同一连通导线的端子归为同一电路节点（板上同色圆点）；采用改进节点分析（MNA，理想电压源与闭合开关作为 0V 电源引入电流未知量）求解；开路显示零电流；电源短路、相互冲突的理想电源、无唯一解（悬空子电路、相同电压电池并联等）给出提示，不输出 NaN 或虚假数值。
  • 灯泡按固定电阻 120 Ω 简化建模，亮度 = 耗散功率 ÷ 1.2 W。

验收记录（Playwright Chromium，file:// 加载，2026-10-14）

  • 12V 电源与 100Ω、200Ω 串联：电池/两电阻/开关电流均 0.04 A ✓
  • 断开串联开关：全电路电流为 0，开关两端电压 12 V ✓
  • 12V 与 100Ω、200Ω 并联：支路电流 0.12 A、0.06 A，电池总电流 0.18 A ✓
  • 并联断开一条支路开关：该支路 0 A，总电流 0.12 A ✓
  • 移动元件后连线数不变（保留连接）✓；删除元件后其 2 条连线被清除 ✓
  • 电池被导线短接：出现短路提示，电流不输出数值，页面无 NaN ✓
  • 不同电压电池直接并联：出现电压冲突提示，无虚假电流 ✓
  • 未接电源的悬空子电路：无唯一解提示，电流为 0 ✓；单个电池开路电流为 0 ✓
  • 390px 视口无页面水平溢出 ✓；加载过程无 JS 错误 ✓

复盘

  • 直接按任务正文实现，未参考其他历史实现。求解核心选择节点法：先用并查集把导线连通的端子合并为节点，再按连通子电路分组，对含电源的分组建立 MNA 方程（节点 KCL + 电压源/闭合开关约束），高斯消元（部分主元）求解，并区分奇异矩阵的一致/不一致情形以给出“无唯一解 / 电源冲突”提示。
  • 调试中修复两处问题（见 run.json changes）：导线端点 id 的键构造错误；闭合开关被提前并入节点导致矩阵奇异。修复后串联、并联数值与验收标准完全一致。
  • 已知简化边界：理想电源并联的电流分配、被导线短接的开关电流等本质不确定的量不输出数值，改为提示；这符合“不伪造有限电流”的要求。
