简化电路实验台

GLM 5.3 / high 于 2026-11-06 在 model-test-base 基线实现的单文件离线电路实验台。

原始提示词

见 完整原始输入。

运行与复盘

  • 入口：本目录 index.html，浏览器直接打开（file:// 或 HTTP 静态托管）即可运行，无外部依赖。
  • 求解：连线经并查集归并为节点（同一连通导线等电位），闭合开关按 0.001Ω 近似理想导通，随后用修正节点分析（MNA）构建线性方程组并以列主元高斯消元求解，实时显示每个元件的电压、电流、功率与电流方向。
  • 验证记录（对应任务验收项）：
    • 12V 电池与 100Ω、200Ω 串联（内置"示例：串联"）：总电流 0.04A，两电阻分压 4V / 8V。
    • 同样两电阻并联（内置"示例：并联"）：支路电流 0.12A / 0.06A，总电流 0.18A。
    • 断开串联示例中的开关后全部支路电流为 0，并显示开路提示。
    • 拖动元件时导线端点跟随；删除元件同时清除其关联导线。
    • 用导线直接接通电池两端会提示"电源短路"；两个不同电压的理想电池直接并联会提示"电路无唯一解"，全程不输出 NaN。
  • 交互：鼠标与触摸统一走 Pointer Events；端子在连线/删除模式下放大命中区域，便于触摸操作。
