运行与复盘

  • 运行方式：浏览器直接打开本目录 index.html（file:// 或 HTTP 静态托管均可），无后端、无 CDN、无构建步骤。
  • 入口：index.html（单文件，HTML/CSS/JS 全部内联）。
  • 实现要点：
    • 元件：理想电池、电阻、开关、灯泡（按固定电阻建模，亮度 = 功率 / 5W）、理想导线；放置 / 拖动 / 删除，端子点击或拖动连线。
    • 求解：导线并查集归并节点；闭合开关按 0V 理想电压源支路处理（MNA），直接解出开关电流；电阻 / 灯泡用电导_stamp；高斯消元（部分主元）求解节点电压与电源支路电流。
    • 错误处理：电源短路（导线或闭合开关短接）、相互冲突的理想电源（并联电压不一致）、相同理想电源并联 / 纯电源回路（无唯一解，按增广矩阵秩区分冲突与不定）均给出中文提示，不输出 NaN。
    • 不含电池的连通岛按零电流处理；断开开关所在支路开路，电流为 0。
    • 预设：串联（12V + 100Ω + 200Ω）、并联（12V + 100Ω ∥ 200Ω），一键重置。
  • 验证记录（2026-11-13，Qoder Desktop 内置浏览器，file:// 打开，脚本断言）：
    • 串联预设：电池 0.04A，电阻电压 4V / 8V，方向左→右。✔
    • 并联预设：支路 0.12A / 0.06A，电池总电流 0.18A。✔
    • 断开开关：全部支路电流 0A。✔
    • 导线短接电池：提示「电源短路」。✔
    • 12V 与 5V 理想电源并联：提示「相互冲突的理想电源」。✔
    • 两个 12V 理想电源并联：提示「无唯一解」。✔
    • 拖动元件保留连线且电流不变；删除元件清除相关连线并重求解为开路。✔
    • 指针事件模拟触摸端子连线成功。✔
    • 灯泡 200Ω 串联：功率 0.32W，亮度 6%。✔
  • 复盘：首版把闭合开关并入节点导致开关电流用 KCL 推算时重复计数（2 倍），且电池支路方程极性写反（电阻电压 / 电流方向反号）。改为「闭合开关 = 0V 电压源支路」后开关电流直接由 MNA 解出，极性修正后全部验收通过。简化模型声明已写在页面顶部与灯泡属性中。
