简化电路实验台（DeepSeek-V4.1-Flash-0731 · high · r01）

单文件静态网页，直接打开 index.html 即可运行。无后端、无 CDN、无远程字体或图片、无构建步骤，file:// 与 HTTP 静态托管都能运行。

原始提示词

见 完整原始输入；任务正文与 v1 任务正文 逐字一致。

实现要点

  • 元件模型：理想直流电池、电阻、开关、按固定电阻建模的灯泡、理想导线。不含交流、电容、电感或半导体。
  • 拓扑：导线与闭合开关把端子用并查集合并成同一个电路节点（同一连通导线 = 一个节点）。
  • 求解：改进节点法（MNA）。节点分析 + 为理想电压源引入支路电流未知量，用带主元选取的高斯消元求解；按连通分量分别求解并各自选取参考点，因此开路支路电流严格为 0，而不是靠近似。
  • 异常处理：
    • 电源两极被理想导线短接 → 明确提示，该支路不给出数值（理想模型下电流不收敛）。
    • 相互冲突 / 彼此并联的理想电源导致矩阵奇异 → 提示“无唯一解”，不输出 NaN，也不伪造有限电流。
    • 被导线短接的电阻/灯泡标为“两端被导线短接”，电压与电流均为 0。
  • 交互：放置元件、拖动元件（连线跟随端子保留）、旋转 90°、端子两点连线（点击或拖动，支持触摸）、切换开关、修改电压/阻值、删除元件（同时清除相关导线）、清除全部导线、串联与并联预设、一键重置。
  • 输出：每个元件的电压、电流与方向箭头、功率；灯泡亮度随耗散功率 P = I²R 变化，并说明是简化模型。

运行与复盘

  • 运行方式：浏览器直接打开本目录 index.html；或使用根目录 npm run preview 后的静态托管地址。
  • 未使用网络资源，断网可用。
  • 复盘：一次实现即通过全部验收项。实现过程中修正了两处自身缺陷——导线初始存的是元件对象而不是 ID（导致拓扑恒为空、全部电流为 0），以及短路电源在结果表中的归类顺序（先按短路标记，再查支路）；两者均在交付前修复并复测。首轮生成后未做人工修改。
