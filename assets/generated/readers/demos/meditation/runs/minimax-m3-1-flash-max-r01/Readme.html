静息 · 冥想 iOS App 原型（MiniMax M3.1 Flash / max）

原始提示词

见 完整原始输入。该输入与主题提示词 v1 正文一致。

实现说明

单文件 index.html，Tailwind CSS 通过 CDN 引入，图片使用 Unsplash 源。全部 7 个页面横向排列在同一页面中，每个页面用 375px 宽的手机外框独立呈现，可直接作为开发参考。

页面规划（产品经理视角）

页面 作用 关键内容
01 今日冥想 每日入口 今日推荐大卡、四个场景入口、连续天数 / 总时长 / 完成次数
02 场景库 内容检索 搜索框、场景筛选标签、带图条目与播放按钮
03 冥想播放页 核心体验 沉浸式背景、进度条、播放 / 前后 15 秒、环境音与定时
04 呼吸引导 工具型功能 呼吸光球动画、4-7-8 节奏文字引导、节奏与时长切换
05 睡眠故事 睡前内容 专题大图、故事列表与播放按钮
06 练习统计 回顾激励 时长柱状图（周 / 月 / 年）、常听场景排行、里程碑进度
07 设置 偏好配置 用户信息、提醒、定时停止、提示音、语言、深色模式

交互

  • 所有播放按钮与播放页联动：点击任意条目会更新播放页标题与按钮状态（▶ / ❚❚）。
  • 场景库按标签筛选条目。
  • 呼吸引导按「吸气 4 秒 → 屏息 7 秒 → 呼气 8 秒」循环切换提示文案，光球用 CSS 动画同步缩放；节奏与时长可切换。
  • 统计页柱状图随「周 / 月 / 年」切换重绘。
  • 底部标签栏在 7 个页面保持一致的导航结构。
