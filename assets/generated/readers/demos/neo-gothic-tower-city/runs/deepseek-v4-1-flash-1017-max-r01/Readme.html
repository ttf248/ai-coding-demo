新哥特式塔楼城市

原始输入

  • 完整原始输入：prompt.md
  • 任务正文版本：v1。

实现说明

  • 单文件 Three.js r160（CDN）场景，入口 index.html；所有几何、材质、纹理程序生成，无外部模型/贴图。
  • 城市：海岛悬崖、海面波浪 shader、新哥特式大教堂（双塔、中央尖塔、玫瑰窗、飞扶壁、侧窗）、12 座塔楼、城墙/塔楼、塔楼之间的桥、房屋、树木、街道灯、旗帜、火焰/余烬、云与星空。
  • 相机：环视模式（拖动旋转、滚轮缩放、WASD 移动视点、闲置自动环绕）与环城模式（低空沿岛屿外圈自动巡游，拖动环顾）。
  • 环境：海面/瀑布/旗帜自定义 shader；月光主光、半球光、暖色边缘光、雾、星点；夜间窗户与城市灯光。
  • 资源失败处理：Three.js CDN 加载失败或 WebGL 初始化失败时显示明确错误，而不是空白页。

验证记录

  • Playwright：场景渲染无控制台/页面错误；12 座塔楼被报告；环视和环城模式切换正常。
  • 无头 Chromium + SwiftShader 下约 25–26 FPS；这是软件光栅器数据，硬件 GPU 表现可能更高。
  • 390px 页面无水平溢出。
  • 相机限制在场景正面与低空环城路径，避免穿过后墙或钻入桌面以下。

复盘

  • 环城模式最初尝试过城墙街道视角，但近距离塔楼/路灯会占满画面；最终改为高度 26m、半径 112m 的低空环城视角，能同时看到塔楼、玫瑰窗、海面与星空。
  • 鸟类点精灵在夜空中呈黑色方块，已移除；保留了星点、火焰和余烬。
  • 未使用外部模型、贴图或音频；“真实比例”以米为单位做比例化表达，不宣称与真实建筑测绘一致。
