新哥特式塔楼城市（MiniMax M3.1 Flash / max）

原始提示词

见 完整原始输入。该输入与主题提示词 v1 正文一致。

实现说明

单文件 index.html，Three.js r160 以 ESM 方式从 unpkg 引入，场景代码全部内联。

场景

  • 真实比例：塔楼主体 34–116m、中央大教堂 152m（尖顶 + 顶饰），环塔与远塔共 24 座，广场半径 74m，漫游视角固定在 1.7m 人眼高度。
  • 程序化建筑：每座塔楼由塔身、竖向壁柱、四棱锥尖顶、四角小尖塔、逐层发光窗与飞扶壁组成；中央大教堂含玫瑰窗、双翼塔楼与十字尖顶。窗为发光平面，按楼层与立面随机取暖黄 / 冷白两色。
  • 海浪：自定义顶点着色器做三组正弦叠加的波形位移，片元着色器按波峰高度混合深浅海色，海浪高度可调。
  • 粒子：10 个火盆各带 90 个火焰粒子（加色混合、逐粒上升循环、随机横向扰动）与一盏脉动点光源；岸边 500 个水花粒子随波浪上下浮动；另有 1400 颗星与一个月亮。
  • 氛围：渐变夜空着色器、指数雾、ACES 色调映射、半球光 + 月光 + 火光。

相机与交互

  • 巡航模式（默认）：相机沿圆弧轨道自动环绕城市，高度与仰角随时间起伏，闲置即可观赏全城。
  • 漫游模式：W / A / S / D 行走（Shift 加速），按住鼠标拖动转向，滚轮改视场角；移动带塔楼与广场边界碰撞检测，起步点自动避开建筑。
  • 点击画布或按任意方向键会从巡航切回漫游。
  • 面板提供移动速度、视场角、海浪高度三个滑块，以及「切换到巡航 / 漫游」「回到起点」按钮。
  • 右上角实时显示模式、坐标与帧率。

待确认（按提示词要求在界面中标注）

  1. 待确认：海浪为正弦叠加的顶点位移，未做真实流体解算。
  2. 待确认：火焰与水花粒子密度按设备性能自适应，桌面端可调高。
  3. 待确认：塔楼比例为真实尺度推演，未引用任何真实建筑图纸。

运行与验证

Playwright + Chromium 自动化校验（模型生成的实现，均通过）：

  • Three.js 场景成功创建 WebGL 画布，错误提示框未显示。
  • 默认进入巡航模式，相机位置随时间变化（97,3 → 97,5）。
  • 可切换到漫游模式；按 W 后坐标由 (0,66) 变为 (0,65)，键盘漫游生效。
  • 视场角与海浪高度滑块可调。
  • 390px 视口无水平溢出；控制台无错误。
  • 已知限制：测试环境为软件渲染，帧率仅 3–8 FPS，真实 GPU 上可流畅运行；Three.js 走 CDN，需联网打开。
