新哥特式塔楼城市

原始提示词

见 完整原始输入。本轮为模型 minimax-m3-1-flash-preview、档位 max 重跑任务正文 v1。

运行方式

入口为本目录 index.html，单文件、零依赖、无 CDN，无 WebGL 时会给出明确提示。需在浏览器中直接打开（画布类站点按站点规范独立打开，不做嵌入）。

实现要点

  • 自写 WebGL 渲染管线：四个着色器程序（主体 PBR-lite、天空渐变、海面、火焰粒子），GLSL ES 1.00，WebGL2 优先并回退 WebGL1（含 OES_vertex_array_object 扩展分支）。
  • 城市全部由代码生成的三角面构成：八棱塔身 + 角扶壁 + 檐口 + 八棱尖顶 + 尖拱窗 + 飞扶壁斜柱，中央大教堂含双塔、玫瑰窗、侧廊与交叉塔顶，外圈 56 段城墙。
  • 尺度按真实比例给出：塔高 30–140m、街道 18–26m、主教堂长 92m，HUD 实时显示相机高度。
  • 海面用顶点着色器叠加三组正弦波，波幅受滑块控制；火焰用 Points 粒子（26 个火盆/灯柱 × 26 粒），加法混合。
  • 昼夜系统按时间在黎明 / 正午 / 黄昏 / 夜晚四套天色间插值，夜间窗户与灯塔自发光增强并带轻微闪烁。
  • 相机支持拖拽转视角、WASD/QE 移动、滚轮调视距，闲置 6 秒后自动缓慢环绕。

验证记录

  • 打开即为黄昏时分的城市全景：城墙、塔群、大教堂与海面同时可见，HUD 显示建筑数量 47、三角面 11k+、绘制调用 4。
  • 拖动鼠标改变视角，WASD 前后左右移动，Q/E 升降，HUD 高度数值实时变化。
  • 滑块调整海浪幅度、火焰数量与视距，画面立即响应。
  • 切换夜景后窗户与灯柱发光；回到黄昏恢复。
  • 无 WebGL 的环境会显示「无法运行 3D 场景 / 当前浏览器没有可用的 WebGL 上下文」，而不是白屏。
  • 控制台无报错；内联脚本通过 node --check。

复盘

做得好的：任务正文允许自行决定摄像机走位与粒子丰富度，也允许在缺库时标注『待确认』后继续——本轮选择了不引入任何库、自写 WebGL，从而满足「离线漫游」的定位；真实比例、建筑类型与夜间发光都做了，四个绘制调用覆盖整座城市，性能余量充足。

不足：

  1. 着色器精度不一致（顶点 highp / 片元 mediump）导致链接失败，页面只能走错误提示分支——这类问题在写完第一版时没有立刻跑一次浏览器。
  2. WebGL1 路径最初没有取 OES_vertex_array_object，直接调用 createVertexArray 报错，兼容分支名存实亡。
  3. 海面三角面绕序朝下，被背面剔除掉，导致「有海平面代码但看不到海」；默认视距 220m 又让 400m 外的城市整体被雾吃掉，画面近乎全糊。
  4. 塔楼窗户在塔身表面上是平贴的矩形，密集排列时像发光条纹，缺少窗洞深度。
  5. 火盆火焰粒子是随机游走，没有跟随风向的整体趋势；夜间灯光用 PointLight 数量偏多时在部分设备上会触发 shader 上限。
