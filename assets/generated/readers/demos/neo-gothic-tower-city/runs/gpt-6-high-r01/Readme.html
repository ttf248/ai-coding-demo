请为我编写一个单 HTML 文件的炫酷网页动画。网页内容是以真实比例重建一个可漫游的 3D 新哥特式塔楼城市。我允许你根据审美自行决定摄像机视角的移动以及海浪、火焰等粒子的丰富度。如果遇到任何局部的环境或库缺漏，请先标示『待确认』并继续完成其他部分，不要停下来问我，偏向采取行动，直到完整页面交付。

场景与操作

原创的新哥特式海上城市，并非某座历史城市的测绘复原。采用 1 场景单位 = 1 米：主塔自基座至尖顶高 184 米，普通门高约 3 米，街巷宽约 6–12 米。建筑包含尖拱窗、玫瑰花窗、飞扶壁、石砌海堤与开放桥洞；海面、天空、窗火、飞鸟和火焰均程序化生成。

  • 默认自动环城巡航，可选择「雾海全景」「圣堂之巅」「长桥灯火」。拖动环绕，滚轮缩放，空格暂停或恢复巡航。
  • 点击「开启自由漫游」或按 F 切换自由飞行。WASD 移动，Q/E 升降，Shift 加速，拖动转向；点击场景可锁定鼠标，Esc 或 F 返回。自由飞行为观察模式，允许穿越建筑。
  • 手机使用拖动转向和屏幕方向按钮前后、左右、升降。
  • 环境设置提供晨光、薄暮、月夜，以及海雾、波浪、巡航速度调节。
  • 环境声按钮开启程序化海风与潮汐；相机按钮导出无界面的 PNG；H 隐藏或恢复界面。
  • 系统开启「减少动态效果」时，默认暂停运镜并减少环境运动。

依赖与兼容

单 HTML 包含 Three.js 引擎（MIT 许可证保留于文件内）、全部 CSS、脚本与程序化纹理，无 CDN、字体、模型或音频网络请求。直接双击 index.html 即可，也支持静态托管。需要启用 JavaScript、支持 WebGL 的现代浏览器；音频在用户点击后初始化。

若 WebGL、鼠标锁定、环境音频或截图能力不可用，页面会显示「待确认」及具体原因；鼠标锁定缺失时可继续拖动漫游。
