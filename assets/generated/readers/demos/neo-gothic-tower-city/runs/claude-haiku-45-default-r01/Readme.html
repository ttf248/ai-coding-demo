入口与运行方式

单 HTML 文件（推荐快速体验）

  • index.html - 直接在浏览器中打开，无需安装依赖，Three.js 通过 CDN 加载
  • 支持所有现代浏览器 (Chrome, Firefox, Safari, Edge)

开发服务器

npm run dev
# 访问 http://localhost:3000

生产构建

npm install
npm run build
# 输出到 dist/ 文件夹

交互控制

  • 🖱️ 拖动鼠标：旋转视角
  • 🔍 滚轮：缩放
  • WASD：移动前后左右
  • 空格/Shift：上升/下降
