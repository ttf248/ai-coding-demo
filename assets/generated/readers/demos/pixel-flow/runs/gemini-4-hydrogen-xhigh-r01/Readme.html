Pixel Flow 图片粒子与手势还原

原始提示词

见 完整原始输入，对应共用任务正文 v1。

实现与功能说明

  • 支持本地图片上传与 3 套内置示范图切换，通过 HTML Canvas 按可调步长采样像素颜色与坐标并生成 Three.js ShaderMaterial 粒子流。
  • 支持 MediaPipe Hands 摄像头实时追踪张开手掌（吸引力场）、双指（扩域加速）、握拳（暂停）等手势，并在无摄像头或离线状态下提供鼠标/触摸力场指针与手工阶段按钮完整体验。
