实现方式

BFS、Dijkstra、A* 三种算法共用同一份网格数据和同一个「生成器式单步推进」框架，每次点击运行后同步推进一步，因此三者的中间过程可以逐格对照，而不是各自跑完再比结果。

  • BFS：等权无权图，队列推进。
  • Dijkstra：带最小堆的贪心松弛，按累计代价升序展开。
  • A*：f = g + h，h 为八方向移动的八角距离启发式。

编辑操作（改墙、改代价、拖起终点）会立即停止正在进行的搜索并清空三者的结果，避免新旧状态混在一起。
