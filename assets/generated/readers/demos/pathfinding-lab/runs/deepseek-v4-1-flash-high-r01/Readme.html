寻路算法实验室（DeepSeek-V4.1-Flash · high · r01）

单文件静态网页，直接打开 index.html 即可运行。无后端、无 CDN、无远程字体或图片、无构建步骤，file:// 与 HTTP 静态托管都能运行。

原始提示词

见 完整原始输入；任务正文与 v1 任务正文 逐字一致。

实现要点

  • 网格 31×19，四方向移动。算法为真实搜索而非固定动画：BFS 用先进先出队列；Dijkstra 与 A* 用二叉最小堆优先队列，A* 的启发函数为到终点的曼哈顿距离（最小单步代价为 1，因此可采纳）。
  • 代价模型：起点代价不计入；进入普通格 +1，进入高代价格 +5。BFS 忽略地形代价，只按步数最少；Dijkstra 与 A* 按累计地形代价。
  • 可视化：搜索前沿（蓝）、已访问节点（深蓝）、最终路径（黄线）、起点/终点标记，均可实时观察。
  • 控制：运行 / 暂停 / 单步（每次正好展开一个节点）/ 速度滑块（指数映射，1 ~ 2048 次每秒）/ 清除搜索 / 重置地图。
  • 编辑：障碍、橡皮、高代价地形、起点、终点五种工具，按住拖动可连续绘制；直接拖动起点或终点网格也可移动。搜索期间编辑地图会立即停止并清除旧搜索，避免混用旧状态。障碍不能覆盖起点与终点。
  • 预设：空地图、经典迷宫（固定种子的递归回溯迷宫）、加权地形、封闭终点，均为固定种子，可重复。
  • 渲染用 Canvas 2D 并按 devicePixelRatio 缩放，指针坐标经矩形变换换算，缩放后仍准确。
