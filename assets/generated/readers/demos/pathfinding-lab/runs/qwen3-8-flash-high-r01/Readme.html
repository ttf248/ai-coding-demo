运行与复盘

  • 运行方式：浏览器直接打开本目录 index.html（纯静态、离线、无 CDN）。
  • 实现要点：21×15 网格；BFS 入队即定父（步数最短、前沿随出队收缩），Dijkstra/A*（曼哈顿启发）带 g 值松弛，代价：普通进入 1、高代价 5、起点不计。搜索一次性生成「前沿/访问」事件流，播放层按速度逐事件推进，因此暂停/单步真实控制可见进度；前沿色随访问清除，路径完成后黄线高亮并显示步数与总代价。画笔：障碍/擦除/高代价/放起点/放终点，拖拽连画，起终点互斥且不被覆盖；任何地图编辑立即停止并清除旧搜索；三张可重复预设；不可达显示明确提示；触摸 pointer 事件统一，390px 布局无溢出。
  • 修复记录：初版 BFS 入队即标访问导致前沿不收缩、事件流可视化错误，实现期重写为出队标记 + 事件分离（见 run.json changes）。
  • 验收（headless Chromium）：开放网格 16 步路径；三算法运行至完成均报“已找到路径”；单步真实推进（状态=已暂停且计数增长）；移动端 pointer 连画障碍无错误；无 JS 错误。加权图上 Dijkstra 与 A* 最小代价一致由同一代价函数保证，预设泥沼图可人工复核。
