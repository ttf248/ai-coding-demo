体素微缩建筑工地沙盘

原始提示词

见 完整原始输入。

运行与验证

  • 入口：index.html。ES Module + import map 加载 Three.js r160（unpkg CDN），需联网且经 HTTP 托管打开；无其他外部资源，全部几何体、材质与木纹贴图由代码生成。
  • 操作：拖动环视（闲置时自动缓慢环绕）、滚轮缩放；点击桌面前方三个实体旋钮分别切换设备运行速度（0.25/0.5/1/2×）、昼夜循环开关（自动 150 秒循环 / 手动切换阶段）、施工尘土强度（关/轻/重）；空格键切换暴雨。
  • 场景要素：实木工作桌 + 沙盘基座；基坑、钢筋加工棚、物料堆放区（钢筋捆/水泥袋/砂石堆）、在建楼房基座（柱/楼板/脚手架）、板房办公区（夜间暖窗）、渣土堆、施工道路；挖掘机×2、渣土卡车×2（接土→行驶→卸料→返回）、塔吊×2（回转/变幅/吊钩）、搅拌罐车、装载机；60 个实例化体素工人；围挡、彩旗、指示灯、灯杆、水电杆、警示标识。
  • 技术：重复元素 InstancedMesh 批渲染（围挡柱、钢筋、水泥袋、工人身体/头盔、彩旗、脚手架、标识等）；尘土为自定义 ShaderMaterial 软粒子；昼夜四阶段天空/雾/太阳/人工光源插值；碰撞约束通过机械固定相位循环与路径设计保证活动范围互不重叠、元素限定在沙盘内。
