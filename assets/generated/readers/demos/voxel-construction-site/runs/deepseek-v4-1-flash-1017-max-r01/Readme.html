体素微缩建筑工地

原始输入

  • 完整原始输入：prompt.md
  • 任务正文版本：v1。

实现说明

  • 单文件 Three.js r160（CDN）场景，入口 index.html；所有模型、材质、桌面纹理、招牌和图纸均由代码生成，无外部模型/贴图。
  • 桌面载体：深色实木桌、蓝图、卷纸、安全帽、卷尺、水平仪、咖啡杯、台灯与三个实体旋钮；背后是带天空 shader 的室内窗。
  • 主工地：基坑与台阶、8 层在建塔楼、脚手架与钢筋、钢筋加工棚、材料场、临时板房、渣土堆、临时道路、围挡、大门与安全牌、临时水电杆和泛光灯。
  • 机械：2 台挖掘机、2 辆循环渣土车、2 台塔吊、混凝土搅拌车、小型装载机；34 名体素工人（绑扎、搬运、指挥、巡逻等）。
  • 动画：挖掘机臂/斗循环、卡车沿样条循环并按装载/卸料点停留与倾卸、塔吊回转/小车/吊钩、搅拌筒旋转、装载机往复、工人行走与手势；卡车/搅拌车/装载机路径与基坑、料场、围挡、工人错开，并在边界内限制。
  • 环境：昼夜循环（黎明/正午/黄昏/夜晚）、天空窗 shader、夜间工地灯/塔吊灯/板房窗、尘土自定义 shader、灯光光晕 shader、按空格或按钮开启暴雨（雨线、湿地面、水洼、灯光增强）。
  • 交互：拖动环视、滚轮缩放、闲置自动环绕；桌面三个实体旋钮（速度/昼夜/尘土）可通过射线点击，顶部控制条与旋钮同步；总览/施工工地/落成街区三个焦点；第二场景“落成街区”在同一桌面。
  • 大量静态体素使用 InstancedMesh 批渲染；工人身体部件也用 InstancedMesh 更新矩阵。

验证记录

  • Playwright：场景加载无控制台/页面错误；统计为 2 台塔吊、2 台挖掘机、2 辆卡车、34 名工人。
  • 三个桌面旋钮的屏幕投影点击后分别改变速度（1→1.5×）、暂停昼夜循环、尘土（1→2），证明实体旋钮可点击并与 UI 同步。
  • 暴雨截图可见雨线、湿地反光/水洼、增强的灯光；总览、工地、落成街区焦点切换正常。
  • 无头 Chromium + SwiftShader 下约 22–26 FPS；硬件 GPU 目标为 60 FPS，但本记录不把软件光栅器结果当作 60 FPS 证明。
  • 390/1440 宽度 UI 无水平溢出。

复盘

  • 自查修复过：工人四肢实例容量与颜色数组不匹配、卡车路径贴近围挡/基坑、卸土时车尾朝向、搅拌车与装载机路径重叠、基坑坡道与料场冲突、旋钮刻度不旋转、THREE 加载失败无提示等。
  • “双场景”落实为同一桌面的在建工地与落成街区；落成街区有独立建筑、公园、路灯、汽车和标志牌。
  • 卡车/塔吊/工人均为程序化运动，碰撞约束依靠预设净空路径和边界限制，不是物理引擎级别的碰撞求解；运动物体设计在各自净空区域内。
