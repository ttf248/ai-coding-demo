体素微缩建筑工地

GLM 5.3 / high 于 2026-11-06 在 model-test-base 基线实现的单文件 Three.js r160 体素工地沙盘。

原始提示词

见 完整原始输入。

运行与复盘

  • 入口：本目录 index.html，Chrome 直接打开。依赖 Three.js r160 CDN（jsdelivr ESM），需联网，加载失败时页面显示明确提示。
  • 场景：深色实木桌面（含蓝图图纸、钢卷尺、安全帽摆件、金属水平仪）上摆放完整工地沙盘：基坑开挖区、钢筋加工棚、物料堆放区（水泥堆/砂石料堆/堆叠钢筋）、在建高层楼基座（逐层脚手架）、临时板房办公区、渣土堆、环形施工道路、围挡+彩旗+大门、水电杆与警示标识。
  • 机械：3 台挖掘机（臂/斗往复挖掘）、2 辆渣土卡车（沿环路循环行驶，近挖机装满、近渣土堆卸空）、3 台塔吊（回转+小车横移+吊钩升降吊运钢筋）、搅拌罐车（环形行驶+罐体旋转）、装载机（铲斗上下）。
  • 人物：17 名体素工人分饰绑钢筋、搬运、指挥塔吊、小型工具与安保巡逻（巡逻者沿大门走动）。
  • 环境与昼夜：黎明/正午/黄昏/夜晚四段插值天色，夜晚探照灯、塔吊灯、板房窗发光；尘土粒子上升漂移；空格键触发暴雨（900 雨滴粒子、雾距缩短、灯光增亮）。
  • 交互：拖拽环视、滚轮缩放、闲置自动缓慢环绕；点击桌面前方三个实体旋钮分别调节设备速度、昼夜循环开关与尘土强度，旋钮转动并有 toast 反馈。
  • 验证记录：连续步进渲染画面持续变化（机械与粒子运动真实推进），控制台无错误；首版使用 three.min.js 触发 r160 弃用告警，已改为官方推荐的 ES Module 动态导入。
  • 边界与穿模说明：全部工地元素限制在 140×140 沙盘边界内；运动以路径参数与固定轨道驱动，避免穿插。约 600 个体素采用共享材质 Mesh 绘制，本规模帧率稳定，未使用 InstancedMesh（如后续扩大规模可改实例化批渲染）。
