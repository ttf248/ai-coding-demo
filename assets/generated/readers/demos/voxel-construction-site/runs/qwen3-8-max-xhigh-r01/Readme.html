体素微缩建筑工地沙盘（Qwen3.8 Max · xhigh）

原始提示词

见 完整原始输入，任务正文版本 v1。正文末尾「添加新场景进去」以可切换的第二场景（玻璃水槽港口码头：门吊 / 集装箱 / 灯塔 / 拖船 / 波动水面）响应。

批次记录

Aliyun 批次合计 91.81 CNY，覆盖 11 个案例，耗时 2h 50m 7s；费用及耗时均为批次总计，不拆分为单案例。

运行方式

  • 入口为本目录 index.html；需联网加载 Three.js r160（unpkg importmap），其余几何体、材质、贴图均为代码生成，无其他外部资源。
  • 交互：拖拽环视、滚轮 / 双指缩放、闲置 6 秒自动环绕；空格触发暴雨；点击桌面前缘三枚实体旋钮（射线拾取）：① 机械速度 ×0.5/×1/×2 ② 昼夜循环开关 ③ 尘土强度三档；按钮与旋钮状态同步。
  • 场景切换按钮在「工地沙盘」与「港口码头」两个桌面微缩场景间切换。

场景内容

  • 房间与桌面：深色实木工作桌（桌腿 / 围板 / 摆件：蓝图、钢卷尺、安全帽摆件、金属水平仪），第三人平视眼高环绕观察沙盘。
  • 工地全要素：基坑开挖区（内含挖掘机）、钢筋加工棚与堆叠钢筋、物料堆放区（木托盘 / 水泥堆 / 砂石料堆）、在建高层楼房基座（分层浇筑 + 脚手架）、临时板房办公区（夜窗发光）、渣土堆放区、临时施工道路环线、围挡与警示彩旗、大门门柱与标识牌、安全警示标识、临时水电杆、四角临时照明灯杆与施工指示灯。
  • 动态机械：3 台挖掘机往复挖掘（动臂 / 斗杆 / 铲斗联动）、4 台渣土车沿环线行驶（挖掘机侧接土→渣土堆抬斗卸料）、3 台塔吊回转 + 小车变幅 + 吊钩起吊钢筋、混凝土搅拌罐车慢速反向巡线、装载机往返平整、门卫与工人沿线行走（步态起伏）。
  • 环境：黎明 / 正午 / 黄昏 / 夜晚四时天色（天空背景、雾色、太阳角度与色温、半球光插值），夜晚板房窗光、灯杆与指示灯加色光晕粒子；尘土粒子自定义 shader 缓缓飘散；暴雨时雨粒子 + 雾密度与灯光增强。
  • 性能与约束：静态体素一次性合批为 InstancedMesh（单 draw call，含实例色）；运动部件为少量动态网格；机械路径与工位分离避免穿模；全部元素限制在沙盘 / 水槽边界内；软件渲染（SwiftShader）自动降质保帧率。

验证记录

2026-10-14 Playwright（Chromium headless + SwiftShader）冒烟测试：

  • Three.js 模块加载、渲染循环运行；状态栏 FPS / 体素实例数 / 天色 / 场景信息正确。
  • 昼夜循环推进且可开关；桌前旋钮①射线点击切换机械速度、旋钮③三档循环到关闭尘土粒子。
  • 空格触发 / 关闭暴雨（截图确认雨粒子）；拖拽环视与滚轮缩放改变画面。
  • 场景按钮切换港口 / 工地双向生效（截图确认水槽港口布局在桌面范围内）。
  • 390px 无水平溢出；桌面与移动端均无 JS 报错；SwiftShader 下 30–60 FPS。

复盘

  • 首版港口场景把水槽布置到了桌面之外（海面悬空在地板上），重排为「桌面前半码头 + 后半玻璃水槽」并让所有港口元素落在水槽边界内，满足「全部工地元素限定在沙盘桌面范围之内」。
  • 渣土车满载 / 空载段按环线路点段号判定（接土段→卸料段满载、卸料点抬斗），避免状态与位置脱节。
  • 旋钮交互用 Raycaster 对三枚圆柱旋钮做拾取，点击循环档位并同步 HUD 按钮文案；调试钩子 __projectKnob/__state 仅用于自动化验证旋钮拾取与状态。
  • 昼夜系统用四关键帧插值（天空色 / 雾色 / 太阳强度与色温 / 半球光），夜窗与光晕强度随夜晚系数联动，避免硬切换。
