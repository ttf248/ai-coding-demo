运行与复盘

这是一个单 HTML 的体素工地沙盘。场景使用代码生成几何体、颜色和灯光，包含基坑、塔楼基座、钢筋棚、板房、道路、塔吊、挖掘机、卡车、工人、尘土和工作台道具；点击“夜间雨暴”会切换到新增的夜间施工场景。

入口为 index.html。Three.js r160 使用 CDN，场景材质和贴图不依赖外部图片；鼠标拖拽、滚轮、空格和前景旋钮可控制视角、天气、灯光及设备速度。
