样式与交互

全部使用 Tailwind CDN 类，无自写 style；Unsplash 摄影和 Lucide Static CDN 图标。375px 手机框横向排列，页内有横向翻页按钮与滑动，外部页面无水平溢出，滚动条隐藏，各框互相独立。

分类状态、喜欢/收藏、订阅、表单草稿、搜索反馈、模拟播放控制可操作。视频为静态视觉原型，点击播放可听示例音；不接入 YouTube 账户、真实上传、视频流、推荐或统计。
