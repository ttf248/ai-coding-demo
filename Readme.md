# AI 编码实验 · 空白测试基线

本分支保留主题、提示词、静态站点和维护工具，不包含历史模型实验、输出文件或复盘。它拥有独立根提交，不继承 main 的提交历史。

从 [测试流程](docs/model-test-workflow.md) 开始。完成测试后，在 main 的新会话中按新增实验目录导入结果。

新增待运行主题见 [本地测试案例清单](docs/test-cases.md)。
