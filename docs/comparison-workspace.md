# 模型效果对比工作区

## 设计

以模型产物为主内容：工具栏与操作行保持紧凑，预览占满剩余窗口，不限制桌面最大宽度。默认双栏，A 为基准，B 可连续切换同正文实验。模型选择在弹层完成，显示模型、档位、轮次、日期、预览状态与输入完整性，支持搜索和已浏览提示。

- 双栏：适合固定基准逐个比较；切换 B 保留 A 的运行状态。
- 四宫格：用户主动开启，最多四个独立预览；资源争用不能作为性能评测依据。
- 单屏：A/B 轮看，占满工作区。手机始终只挂载当前版本，四宫格在手机上提供 A/B/C/D 切换。
- 放大：临时聚焦单个面板，其他面板卸载；还原后重新加载其他面板。
- 自适应视口：利用面板可用高度与共同宽度。固定视口：保留相同逻辑尺寸，等比缩放居中，完整显示画面。

任务正文和完整原始输入分别比较，C/D 的输入差异以 A 为基准。信息缺失、人工修改和工具差异仍在实验信息中保留。无预览及外部不可嵌入版本可正常选择，提供说明和独立打开入口。

## 使用与状态

主题页的提示词详情提供“比较此提示词的全部实验”入口。顶部选择主题/提示词后自动填入实验；选择模型弹层支持任务正文一致、已记录原始输入一致、整个主题及全部实验。面板下拉框保留旧版的相关主题筛选，方便跨提示词手动比较。

布局、提示词组、比较范围、A/B/C/D 实验及页面、当前手机侧、放大状态和视口记录在 URL 中；旧版 left/right 链接继续可用。已浏览状态仅保留在当前页面会话内。

## 实现与验证

修改范围为 compare.html、assets/compare.js、assets/site.css 与主题入口 assets/topic.js，不修改历史实验或发布配置。浏览器回归覆盖根路径、Pages 子路径、固定基准保留、版本搜索、四宫格和分享恢复、单格放大、手机单侧加载以及预览区域尺寸。
