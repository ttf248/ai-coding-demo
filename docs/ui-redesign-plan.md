# 展示与对比体验改造方案

## 设计目标

让访问者沿着“浏览作品 → 选择实验 → 看懂差异 → 核对原始记录”完成阅读。首页突出作品，主题页承担筛选与选择，对比页并列展示截图和证据，文档承接细节。统一浅灰背景、白色表面、蓝色主操作、灰色辅助文字及数字排版。

评分始终称为截图评分，只解释已有证据；同任务、同规则才展示分差。证据不足、无截图与待评分分别保留，不视为零分。费用和耗时保留单次/批次口径、币种与额度单位，不计算虚构的单次成本。不修改历史输入、截图、评分或部署方式。

## 执行任务与独立提交

1. 方案：记录设计、实施边界与验收方式。
2. 评分与数据表达：共享五维条形图、证据状态、取景和评语展示；为主题与对比复用。
3. 主题页：缩略图和评分优先；六列精简记录表，执行条件折叠；同任务内评分排序；覆盖矩阵精简；手机卡片适配。
4. 对比页：默认截图，集中空状态，模式相关控件，截图下方数据对照，整合实验详情，兼容旧分享链接；手机保留单侧运行。
5. 首页：评分去重、明确全站累计与筛选口径、实验数术语统一、精简卡片操作与技术统计。
6. 视觉统一：导航、选中态、按钮、表格数字、间距与可访问焦点规则统一。
7. 辅助页面：文档阅读宽度和目录高亮、实验文档快捷入口、技术示例外围导航和 404 风格统一。

每个任务完成后独立提交，只提交对应源码、测试及生成结果。任务产生的生成文件由 generate 更新，不手工修改。

## 验收

每次提交前运行 generate、validate、npm test、node --check index.js、git diff --check。首页和对比交互改动运行完整浏览器测试，主题页执行相关浏览器测试；最终执行完整浏览器回归，覆盖根路径与 Pages 子路径。

检查 1440px 和 390px，页面不得水平溢出；桌面截图保持原比例、手机只运行当前侧。验证选择、筛选、排序、返回/分享恢复、无截图、无预览和同/异输入。静态链接与生成文档须可直接由仓库托管。历史示例只统一外围导航，不重写示例内容。

## 实施结果（2026-10-15）

七项任务均已落地，按任务独立提交。主要使用路径：

- 首页展示真实截图、模型及档位，每张卡片只保留一处截图评分；加入对比选择当前展示的实验。
- 主题默认记录表支持缩略图、同任务内评分排序、五维评分与评语；运行工具和供应商等执行条件按需展开。
- 对比默认使用截图，数据摘要显示已记录费用、耗时和输入关系。实验详情统一展示条件差异；旧 `tab=info` 链接兼容进入详情。
- 全站统一导航、主操作、选中态、评分条与数字排版。实验文档提供主题、运行作品和对比入口，侧边目录跟随当前章节。
- 技术示例统一外围导航，历史示例内容保持原状；404 保留迁移查找和归档搜索。

验收：generate、validate、32 项单元测试、JavaScript 语法与 diff 检查通过。完整浏览器回归 205 项通过，1 项按既有规则跳过（子路径项目不重复执行 file:// 测试，根路径已执行）。根路径和 Pages 子路径覆盖筛选、排序、四侧选择、分享恢复、输入关系、无预览、移动端和单侧卸载。首页、主题、对比、实验文档、技术示例与 404 在 1440px / 390px 实测无页面横向溢出。

所有实验阅读页由生成器更新；原始实验源码、输入、截图与评分未修改。发布方式、域名、同步与外部部署配置保持原样。

补充验收：新增的实验文档快捷入口与目录高亮测试在根路径、Pages 子路径均通过（2 项），验证跳转保留实验 ID、预览链接可访问及手机端阅读无横向溢出。

## 案例清单专项优化（2026-10-16）

设计围绕“浏览作品 → 缩小范围 → 挑选实验 → 开始对比”展开，拆为三个独立提交：

1. 清单密度与定位：默认桌面三列紧凑视图，保留大图和列表；分类、复杂度收入实验信息。增加可运行、有截图、多模型可对比快捷筛选。实验列表对齐截图、主题、模型档位、截图评分、日期与操作，支持当前已加载记录按主题分组。返回清单保留筛选、加载数量、滚动位置，并标出刚查看的案例。
2. 主题快速挑选：点击卡片模型/实验数量打开候选弹窗，沿用首页筛选。按任务版本分组，支持同规则截图评分排序、最近更新排序和分批加载；候选展示真实截图、模型档位、输入留存状态及评分。任务版本和排序通过 URL 恢复，弹窗提供查看全部实验和开始对比。
3. 对比选择引导：仅选一条时提供“寻找同任务实验”；首页在弹窗中展示所选主题及任务版本的候选，明确提示该入口不受首页筛选限制。主题页回到该任务版本列表。沿用四条选择上限、替换操作和跨页选择记录，手机端压缩对比栏操作区。

“多模型可对比”只筛选当前范围内任务正文指纹相同、至少包含两个已知模型的记录，不表示原始输入、工具或执行条件相同。截图评分不代表运行性能；缺少证据的记录仍使用既有证据状态。

专项验证覆盖根路径与 Pages 子路径上的快捷筛选、分组列表、返回定位、弹窗恢复、加载更多、选择状态和手机布局。沿用全站生成、数据校验、单元测试、语法检查、链接和浏览器回归流程。

验收结果：generate、validate、32 项单元测试、JavaScript 语法及 diff 检查通过。全量浏览器回归加修正后的定向复测覆盖 217 项通过，1 项按既有规则跳过；其中原有的复杂度标签断言改为验证默认折叠、展开可见。1440px 与 390px 检查通过，生成数据和历史实验内容未产生变更。
