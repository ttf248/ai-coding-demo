# 寻路算法实验室 · 任务正文 v1

实现一个完整可交互的纯静态单文件网页，入口为 index.html，HTML、CSS、JavaScript 均包含在文件内。不使用后端、CDN、远程字体、远程图片或构建步骤；通过 file:// 直接打开和 HTTP 静态托管均可运行。界面采用中文，兼容桌面鼠标和移动端触摸，390px 宽度无页面水平溢出。所有控件必须实际生效，提供清晰的操作说明、重置功能和必要的错误提示。不要仅制作界面或用固定动画冒充计算。

制作网格寻路算法实验室。支持 BFS、Dijkstra 和 A*，四方向移动，A* 使用曼哈顿距离。用户可以绘制或擦除障碍、设置高代价地形、拖动起点和终点。显示搜索前沿、已访问节点、最终路径、路径步数及总代价。明确 BFS 按步数搜索，Dijkstra 和 A* 按地形代价搜索；起点代价不计入，普通格进入代价为 1，高代价格为 5。支持运行、暂停、单步、速度调节、清除搜索和重置地图。搜索期间编辑地图应停止并清除旧搜索，防止混用状态。提供可重复的预设地图。

验收：无障碍网格路径正确；封闭终点明确显示不可达；加权地图上 Dijkstra 与 A* 得到相同最小代价；BFS 展示步数最少路径；暂停和单步真实控制搜索；起终点不可被障碍覆盖；移动端可编辑地图。
