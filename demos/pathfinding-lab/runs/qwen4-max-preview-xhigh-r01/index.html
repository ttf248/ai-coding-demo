操作说明
  1. 障碍 / 高代价 / 擦除工具：点击或拖动绘制；起点 / 终点工具：点击放置（不可放在障碍上，障碍也不能覆盖起终点）。
  2. 运行：按速度滑块逐帧展开搜索；暂停 / 继续真实控制；单步每次只展开一个节点。
  3. 蓝色为已访问，黄色为搜索前沿，绿色为最终路径；统计区显示步数与总代价。
  4. BFS 忽略地形代价，只保证步数最少；Dijkstra / A* 保证总代价最小（加权地图上两者代价相同）。
  5. 搜索期间编辑地图会立即停止并清除旧搜索，防止混用状态。
  6. 预设地图可重复：空网格、迷宫、加权谷地、不可达。
