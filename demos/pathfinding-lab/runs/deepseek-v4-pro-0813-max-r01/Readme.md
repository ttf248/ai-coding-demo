## 复盘

- 直接按任务正文实现。BFS 用队列，Dijkstra/A* 用二叉堆（f 值、g 值二级比较），路径用 prev 数组回溯；已访问/前沿分别以独立位图维护，供逐帧着色。
- 验收中发现两处需修正（见 run.json changes）：BFS 总代价误显示为步数；加权地形预设最初无法形成“步数-代价”权衡（无障碍时任何单调路径步数相同），改为“墙块 + 高代价通道”设计后 BFS（26 步/代价 38）与 Dijkstra/A*（28 步/代价 28）的差异清晰可见，Dijkstra 与 A* 代价相等符合验收要求。
- 已知简化：启发式与代价满足一致性（曼哈顿 ≤ 实际代价），A* 保证最优；不同最优路径之间的选择取决于堆的平局处理，属正常现象。
