## 实现说明

单文件 `index.html`，HTML / CSS / JavaScript 内联，无后端、无 CDN、无构建步骤。

- 网格 24 × 16，四方向移动，障碍不可穿越。
- 代价规则：起点不计入代价，普通格进入代价 1，高代价格进入代价 5，障碍为 `Infinity`。
- 三种算法共用同一套扩展逻辑：
  - **BFS**：每步代价固定为 1，最小化路径步数（另单独统计该路径的地形代价，便于对比）。
  - **Dijkstra**：按地形代价累加，最小化总代价。
  - **A***：目标与 Dijkstra 相同，启发函数为曼哈顿距离（四方向移动下可采纳）。
- 前沿用二叉堆最小堆实现；堆内允许旧节点残留，弹出时用 `g` 过期检查丢弃，保证与标准实现一致。
- 可视化：浅蓝为搜索前沿，深蓝为已访问节点，绿色为最终路径，红绿点为起点 / 终点。
- 交互：拖动绘制障碍 / 高代价地形 / 擦除；`移动起点`、`移动终点` 工具点击即可改位置（目标格的地形会被清除，起终点不会被障碍覆盖）。
- 运行控制：运行 / 暂停、单步（一次只扩展一个节点）、速度滑杆、清除搜索、重置地图；搜索过程中修改地图会立即停止并清除旧结果。

## 运行与验证

Playwright + Chromium 自动化校验（模型生成的实现，均通过）：

- 空旷地图 BFS：路径 34 步（等于曼哈顿距离 21 + 13），总代价 34。
- 权重对比图：BFS 得 27 步、地形代价 63；Dijkstra 与 A* 均得 33 步、代价 33，三者按各自度量取到最优。
- 封闭终点预设：A* 状态为“终点不可达”，不输出任何路径。
- 蛇形迷宫：A* 可达并给出 176 步路径。
- 单步：每调用一次只新增一个已访问节点（1 → 2）。
- 390px 视口 `scrollWidth == clientWidth`；可在画布上拖动绘制地形；控制台无错误。
