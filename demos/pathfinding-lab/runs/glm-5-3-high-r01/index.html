寻路算法实验室

BFS 按步数搜索，Dijkstra 与 A* 按地形代价搜索；四方向移动，A* 启发函数为曼哈顿距离。起点代价不计入，普通格进入代价 1，高代价格为 5。

结果统计

访问节点 0 前沿节点 0 路径步数 — 总代价 —
障碍 高代价地形（进入代价 5） 已访问 搜索前沿 最终路径 起点 终点
操作说明
  1. 在画布上按住拖动即可用当前工具连续绘制；切换到"移动起点/终点"后点击目标格即可移动，起终点不会被障碍覆盖（放到障碍上会自动清除障碍）。
  2. "运行"逐步展示搜索过程：浅蓝为已访问，亮蓝为当前前沿；完成后路径以深蓝高亮并统计步数与总代价。BFS 保证步数最少，Dijkstra 与 A* 保证总代价最小。
  3. 搜索过程中绘制/擦除地图会自动停止并清除本次搜索，防止状态混用。
  4. 终点被完全围住时搜索会自然穷尽所有可达格，并明确提示"终点不可达"。
  5. 触摸设备同样支持拖动绘制与起终点拖放。
