## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开即可，无外部依赖。
- 算法：BFS 按步数扩展（高代价地形不改变扩展顺序），Dijkstra 与 A*（曼哈顿启发）按地形代价扩展；四方向移动，起点代价不计入，普通格进入代价 1、高代价格为 5。
- 可视化：浅蓝为已访问、亮蓝为搜索前沿、深蓝为最终路径；统计访问节点、前沿规模、路径步数与总代价（BFS 的总代价按路径实际地形代价求和，扩展顺序仍按步数）。
- 验证记录（对应任务验收项）：
  - 无障碍网格三种算法路径步数一致且正确。
  - 人工构造的"高代价捷径 vs 绕行"地图：BFS 选 4 步穿过高代价区（地形代价 16），Dijkstra 与 A* 均选绕行路线且代价一致（6），最小代价相同。
  - 终点被障碍完全围住时提示"终点不可达"，不伪造路径。
  - 暂停/单步直接控制搜索步进；搜索进行中绘制或擦除地图会立即停止并清除本次搜索状态。
  - 放置起终点时若目标格是障碍会自动清障，起终点不会被障碍覆盖。
- 交互：Canvas + Pointer Events 统一支持鼠标与触摸拖动绘制；速度滑杆调节每帧扩展节点数。
