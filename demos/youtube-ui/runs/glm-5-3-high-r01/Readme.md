## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开。需联网（Tailwind CDN、Lucide Static CDN 图标、Unsplash 图片）。
- 实现方式：严格按任务正文要求——Tailwind CSS CDN 完成全部样式（仅保留极小段隐藏滚动条的基础样式），图标全部使用 Lucide Static CDN（`https://unpkg.com/lucide-static@latest/icons/XXX.svg`），图片全部使用 Unsplash；界面不出现滚动条（无横向滚动，纵向滚动条隐藏）。
- 信息架构：按功能拆分为 4 个功能模块，每个功能的所有页面写入同一 HTML，页面各自置于独立的手机 mockup 边框（320×680 圆角玻璃边框）内横向排列，互不影响：
  - 功能 1 · 首页信息流：推荐视频流（直播卡片、视频列表、分类 chips、玻璃底部导航）、侧边抽屉导航（用户区、快捷入口、订阅列表）。
  - 功能 2 · 视频播放：播放页（玻璃控制层、进度条、操作栏、频道信息、推荐位）、评论底部面板（置顶作者回复、评论项、输入栏）。
  - 功能 3 · Shorts 短视频：竖屏沉浸流（右侧玻璃互动栏、音乐 ticker）、评论互动面板。
  - 功能 4 · 频道与订阅：频道主页（banner、订阅/通知/加入按钮、Tab、2×2 视频网格）、订阅管理（最近更新、NEW/LIVE 徽标、稍后观看）。
- 视觉：深色紫红氛围光斑背景 + 全局玻璃拟态（`bg-white/10` + `backdrop-blur`），YouTube 红色品牌点缀，玻璃底部导航与圆角胶囊控件。
- 验证记录：113 张图片（78 Lucide + 35 Unsplash）全部加载成功无破图，Tailwind JIT 生效（backdrop-filter blur(40px) 实测应用），无横向滚动条，控制台仅 Tailwind CDN 的生产环境提示（CDN 方案为任务正文要求）。
