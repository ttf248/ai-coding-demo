UI/UX REFERENCE · DESIGN SPEC V1

YouTube UI 模块拆解

按功能模块拆成五组：把复杂产品还原成可逐块开发的信息架构。每组把该功能的所有页面横向排列在同一 HTML 中，每个页面放在独立的 mockup 边框内，状态互不共享；mockup 内不出现滚动条。

设计语言

深色底 #0f0f0f + 毛玻璃浮层；品牌红只用于播放、订阅与活跃态；圆角 12–22px；8pt 栅格；缩略图统一 16:9。

交互与独立性

每个 mockup 是独立画布，点击卡片、Tab、点赞只在当前画布内生效；顶部导航、底栏与悬浮层用玻璃拟态，避免与内容争抢注意力。

资源约束

Tailwind CSS CDN 驱动样式，不手写组件样式；缩略图来自 Unsplash；图标全部通过 Lucide Static CDN 引入，不手动输出 SVG 路径。
