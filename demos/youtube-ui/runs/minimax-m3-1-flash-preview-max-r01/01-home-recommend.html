设计规范

色彩与材质

底色 #070910，主色 #FF4D5E，辅助 #7C5CFF；所有浮层统一 rgba(255,255,255,.07) 玻璃层 + 1px 半透明描边 + 18px 背景模糊。

图标与图片

图标统一使用 Lucide Static CDN（unpkg.com/lucide-static），通过 CSS mask 着色，因此跟随文字颜色；图片使用 Unsplash CDN。

移动端约定

375 × 812 基准，顶部安全区 44px、底部 Tab 78px；所有可滚动容器加 scrollbar-width:none，界面中不出现滚动条但保留惯性滚动。

可点区域

列表项、按钮、chips 的可点范围不小于 40px；删除等破坏性操作在 1.3 用独立区域并配文字说明，不与主操作混排。
