设计规范（贯穿全部 7 个模块）

色彩

底 #070910，主色 #FF4D5E，辅助 #7C5CFF，正向 #5FE3B5。玻璃层统一 rgba(255,255,255,.07) + 1px 半透明描边 + 18px 模糊。

圆角与间距

圆角四档：10（控件）/ 16（卡片）/ 24（大卡）/ 36（设备框）。间距基于 4px 栅格，页面左右留白统一 16px。

图标与图片

图标全部来自 Lucide Static CDN（unpkg.com/lucide-static），通过 CSS mask 着色以跟随文字颜色；图片使用 Unsplash CDN，统一 2:3 或 16:9 两种裁切比例。

移动端约定

375 × 812 基准；顶部状态区 44px、底部 Tab 78px（含 20px 安全区）；所有滚动容器隐藏滚动条但保留惯性滚动，界面中不出现任何滚动条。
