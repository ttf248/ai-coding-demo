产品需求与设计原则

目标用户

移动端重度视频消费者与创作者。核心诉求：快速发现内容、沉浸式播放、便捷管理个人库与创作数据。

视觉语言

YouTube 深色模式（#0F0F0F）+ 玻璃拟态卡片（backdrop-blur / 半透明白 / 细描边），品牌红 #FF0033 用于关键操作与状态。

交互细节

底部五栏导航、卡片溢出菜单、底部弹层（评论/设置）、迷你播放器、Shorts 全屏手势区；所有界面隐藏滚动条。
