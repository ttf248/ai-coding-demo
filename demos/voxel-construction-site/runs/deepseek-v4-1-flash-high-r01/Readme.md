## 实现要点

- **尺度**：1 体素 = 0.02 m。工作桌面 2.6 × 1.8 m；沙盘占地 1.76 × 1.16 m，共 13,089 个静态体素，全部落在桌面上。挖掘机机身 0.28 m，塔吊 1.05 m，板房层高 0.17 m，工人 0.09 m。
- **分区**：左后钢筋加工棚、中后在建楼房基座（钢筋柱 + 脚手架）、右后物料堆放、左中与中中基坑开挖（挖掘机环绕）、右中塔吊、左前新增环保设施区、中前渣土堆与装卸点、右前临时板房与门卫。
- **新增场景**（题面末尾「添加新场景进去」）：场地西南角的三级沉淀池 + 车辆洗车槽，沉淀池用隔墙分三级并带水面，洗车槽为下沉混凝土槽并架设喷淋管。
- **性能**：13,089 个静态体素合并为**一个 InstancedMesh**（1 次 draw call）；机械零件用 `mergeGeometries` 按部件合并，每台机械只有数个网格；56 名工人用一个 InstancedMesh + 每帧矩阵更新驱动动作。设备像素比上限 1.5，阴影贴图 2048，4 盏探照灯只在夜间开启。
- **不穿模的约束方式**：所有静态元素按米制矩形分区摆放并做重叠检查；挖掘机机身完全落在基坑之外，只让铲斗探入坑内作业；渣土车的整条往返车道位于基坑以东，不穿越坑体；塔吊吊臂以「朝向场地中心」为基准摆动（摆动幅度 0.42~0.5 rad），吊钩最低高度 0.28 m 高于场内最高构筑物 0.24 m，因此吊物既不越出沙盘也不穿过建筑。
- **昼夜循环**：太阳按时间沿弧线升落，天色在黎明 / 正午 / 黄昏 / 夜晚之间连续插值；夜间探照灯与板房窗户亮起；暴雨时照明亮度提升（题面要求）。
- **暴雨**：空格切换。雨滴粒子（自定义着色器）、天色压暗、地面湿滑——所有体素与机械材质在雨中降低粗糙度并提高金属度，灯光在表面拖出高光。
- **交互**：拖拽环视、滚轮缩放、闲置 20 秒后自动缓慢环绕；点击桌面前方的三个实体旋钮分别切换「设备运行速度 / 昼夜循环 / 施工尘土」，旋钮指示角随设置转动，右上角面板同步显示当前值。

## 运行与复盘

- 运行方式：联网状态下用浏览器直接打开本目录 `index.html`；或使用根目录 `npm run preview` 后的静态托管地址。
- 复盘：首轮生成后经多轮自查修正，均为首轮内部问题，不属于部署适配，`changes` 为空。主要修正：① 静态体素全黑——`vertexColors: true` 会让着色器去读几何体的 `color` 属性，而 InstancedMesh 的逐实例颜色需要几何体自带（白色）颜色属性才能相乘生效；② 场景雾密度误设为 0.42，2 米外即有 50% 雾，整体糊成褐色；③ 分区初版有重叠，且道路半径超出场地，重排为按米制矩形分区的布局；④ 塔吊吊臂会扫出沙盘边界，改为以场地中心为基准的内向摆动并缩短臂长；⑤ 湿滑效果原先只改了一个未被任何网格使用的材质，已改为遍历所有体素质感材质；⑥ 围挡原高 0.25 m（约为工人身高的 2.8 倍），降到 0.18 m。此外还加粗了雨滴并压暗雨天天色。
