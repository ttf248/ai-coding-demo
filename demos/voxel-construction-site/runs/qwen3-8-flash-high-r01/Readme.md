## 运行与复盘

- 运行方式：HTTP 或 file:// 直接打开本目录 index.html；three.js r160 走 unpkg importmap，必须联网（不标记离线）。
- 实现要点：室内深色实木工作台（四条腿、蓝图图纸 CanvasTexture、钢卷尺+拉带、安全帽摆件×3、金属水平仪带发光气泡），沙盘限定 30×20 边界内。一标段：基坑（下沉+支护壁+钢筋网）、钢筋加工棚、物料堆（钢筋束/水泥袋/锥形砂石堆）、逐层收分在建基座+钢框架+玻璃、板房办公区（夜间暖窗 emissive）、渣土堆、环线路+双黄线、红白围挡与大门、警示牌、照明杆。动态：双挖掘机往复挖斗+回转，两台渣土卡车沿 CatmullRom 环线循环（近坑减速段/卸料段举斗并显示载土）、两台塔吊回转+小车+吊钩吊运钢筋料（交替载/空）、混凝土搅拌车缓行罐体旋转、装载机短程往复举斗、7 名工人各司绑扎/搬运/指挥/巡逻、彩旗摆动。昼夜四相插值循环（黎明/正午/黄昏/夜晚天空雾光色）+ 夜间探照灯火，GPU 尘土粒子（自定义 shader，多发射点上升扩散），空格暴雨：雨滴 shader、桌面材质变暗增光模拟湿滑反光、灯光亮度提升。交互：拖拽环视/闲置 4s 自动环绕/滚轮与双指缩放、桌前三个实体旋钮（raycast 点击，与 HUD 按钮同源：设备速度/昼夜循环/尘土强度）。静态体素全部 InstancedMesh 批渲染；运动件路径参数化（无物理穿插，卡车/罐车共用道路样条，吊钩垂直限位）。提示词末句“添加新场景”按新增二标段高架桥场景实现：河道、桥墩×4、已架/待架箱梁、预制场，动态门吊巡航吊装合龙段 + 桥面工人。
- 验证（headless Chromium）：WebGL canvas 创建、无致命脚本错误（CDN 失败有明确提示兜底）。60FPS 目标在 SwiftShader 下未做性能断言，桌面 Chrome 实测交人工复测。
- 修复记录：实现期清理 resize 重复调用与灯光增强死代码。
