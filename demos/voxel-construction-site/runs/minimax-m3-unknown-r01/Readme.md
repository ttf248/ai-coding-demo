## 运行与复盘

按主题 v1 任务生成单 HTML 体素微缩建筑工地场景，部署在深色实木工作桌面上。

实现要点：

- Three.js r160 CDN；InstancedMesh 批渲染（机械、工人在场景中共享基元）。
- 自定义 ShaderMaterial：灰尘粒子、雨滴、湿地反光、灯光光晕。
- 场景 1「在建高层工地」：基坑开挖区、钢筋加工棚、物料堆放区、在建高层基座、临时板房、渣土堆、临时道路。
- 场景 2「桥墩施工」：桥墩、桥面、水面、块石。
- 动态机械：体素挖掘机（铲斗 IK）、轮式渣土卡车循环（挖掘机旁接土 → 渣土堆卸料）、三台塔式塔吊回转吊运、混凝土搅拌罐车、小型装载机平整地面。
- 工人：绑扎钢筋、搬运建材、指挥塔吊、操作工具、安保巡逻。
- 细节：围挡、警示彩旗、施工指示灯、临时照明、脚手架、堆叠钢筋、水泥堆、砂石堆、施工大门、临时水电杆、安全标识。
- 环境：完整日夜循环（黎明 / 正午 / 黄昏 / 夜晚四套天色 + 夜晚探照灯 / 塔吊灯 / 板房窗辉光）+ 尘土粒子。
- 交互：
  - 鼠标拖拽环视；闲置自动缓慢环绕。
  - 滚轮缩放。
  - 桌面旋钮：调速 / 昼夜切换 / 尘土强度。
  - 空格键：触发暴雨（雨滴 + 湿地反光 + 灯光亮度提升）。
- 所有动态对象做约束，避免穿模；限定在桌面范围。

直接打开 `index.html` 即可（联网加载 Three.js）。
