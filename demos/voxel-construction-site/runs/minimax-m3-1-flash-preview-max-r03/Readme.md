# 体素微缩建筑工地沙盘

## 原始提示词

## 运行方式

入口为本目录 `index.html`，单文件。通过 importmap 引入 Three.js r160，**需要联网**加载 CDN 资源；模型与贴图全部由代码生成，不引用任何外部素材。

## 实现要点

- 体素渲染走 `InstancedMesh`：按颜色分组合并全部静态方块，单场景 10 个实例网格承载 400+ 体素。
- 两个场景：施工工地（基坑、钢筋棚、在建高层、临时板房、渣土堆、施工道路）与跨江大桥（主塔、斜拉索、桥墩、移动模架），通过界面按钮或数字键 1/2 切换。
- 动态机械：挖掘机（回转 + 斗杆往复）、轮式卡车（沿路线循环 + 装卸土方）、两台塔吊（回转 + 吊钩升降）、混凝土罐车、装载机、桥梁桁架吊装车与浇筑车。
- 人物：12 名体素工人，按各自相位做手臂摆动与迈步动画。
- 昼夜四套天色 + 暴雨系统：雨滴粒子、湿滑反射地膜（`roughness` 0.08）、灯光提亮。
- 尘土用自定义 `ShaderMaterial` 粒子（位置随时间漂移、透明度按高度衰减），强度可调。
- 交互：拖拽环绕、滚轮缩放、闲置 8 秒自动环绕；**点击桌面正前方的三只实体旋钮**分别调节设备速度、昼夜循环与尘土强度，旋钮指针会随参数实时转动。

## 验证记录

- 打开即为桌面上的一整个微缩工地：深色实木桌、蓝图图纸、钢卷尺、安全帽摆件、水平仪、铅笔全部可见，HUD 显示体素块 405、实例网格 18。
- 切换到桥梁场景后主塔、斜拉索、桥墩与江面完整渲染（体素块 238）。
- 切到夜晚并开启暴雨：工地灯与塔吊灯亮起，雨滴下落，地面出现湿滑反光。
- 点击三只旋钮：设备速度 1.0 → 1.5、机械运转明显加快；尘土强度旋钮改变粒子浓度；昼夜循环旋钮切换后按钮状态同步。
- 空格可触发 / 关闭暴雨，界面顶部出现状态胶囊。
- 控制台无报错。

## 复盘

**做得好的**：任务正文对体素工地提出了非常细的清单（分区、机械、人物、围挡、昼夜、交互），本轮基本逐项落到场景里，并且用 `InstancedMesh` 而不是逐个 Mesh 来满足性能要求；「添加新场景进去」这条额外要求以第二个桥梁场景兑现，切换逻辑干净。实体旋钮是可点的三维物体，不是复刻的 HTML 控件。

**不足**：
1. 桌面摆件的尺度最初按真实办公桌比例摆放，而工地占 40×30 个世界单位，结果卷尺和安全帽看起来比整座工地还大；调相机时才发现比例失衡。
2. 罐车的朝向计算有恒等式化简的错误（`f > 1 ? 24 : 24`），行驶时车身不会转向。
3. 粉尘 shader 的透明度与场景底色对比不足，白天几乎看不见。
4. 阴影贴图固定 2048，软阴影在软件渲染下帧率很低（真实 GPU 上应无碍，但没有做过低性能设备验证）。
5. 场景里没有做碰撞约束，几何上是靠手工摆放对齐，机械臂与卡车路径也没有避让逻辑，正文提到的「杜绝穿模」只是摆放上成立而非机制上保证。
