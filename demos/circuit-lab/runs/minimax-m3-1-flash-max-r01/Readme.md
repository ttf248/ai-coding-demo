见 [完整原始输入](prompt.md)。该输入与主题提示词 v1 正文一致。

## 实现说明

单文件 `index.html`，HTML / CSS / JavaScript 全部内联，无后端、无 CDN、无构建步骤，file:// 直接打开与 HTTP 静态托管均可运行。

### 电路模型

- 元件：理想直流电池（可调电压）、电阻、灯泡（按固定电阻建模）、开关（可开合），元件之间用理想导线连接。
- 节点：导线与闭合开关视为理想导体，用并查集合并为**电路节点**；求解面板与画布上会显示每个端子所属的节点编号。
- 求解：使用**改进节点法（MNA）**。节点电压为未知量，理想电压源（电池）与理想导体（导线、闭合开关）以 0V 电压源形式写入方程，电阻与灯泡按电导写入；高斯消元（部分主元）求解。
  - 电流定义：电阻/灯泡电流按端子 0→1 方向；电池输出电流为正极流出电流；导线与开关电流按端子 0→1 方向。
  - 理想导体之间并联时电流分配不唯一，按“不可唯一确定”处理，不输出伪造数值。

### 交互

- 左侧面板放置元件；拖动元件本体可移动（连接随端子走，连接关系不变）。
- 从一个端子圆点拖到另一个端子即完成连线，鼠标与触摸都可用；删除模式下点端子会删除该端子上的所有连线。
- 选中元件后在右侧修改电压、阻值、灯泡额定功率，切换开关状态；点击开关本体上的拨杆也能直接开合。
- 顶部消息区给出短路、理想电源冲突、无唯一解、孤立电路等提示。

### 预设

- **串联预设**：12V 电池 + 闭合开关 + 100Ω + 200Ω。
- **并联预设**：12V 电池 + 闭合开关 + 100Ω ∥ 200Ω。

## 运行与验证

- 直接打开 `index.html`（file://）与经本地静态服务器访问均已验证；页面无外部请求。
- Playwright + Chromium 自动化校验结果（模型生成的实现，均通过）：
  - 串联：总电流 0.04A，100Ω 上 4V / 0.04A，200Ω 上 8V / 0.32W。
  - 并联：支路电流 0.12A 与 0.06A，总电流 0.18A。
  - 断开开关后两条支路电流均为 0A。
  - 直接短接电池正负极时给出“电源短路”提示，且所有电流显示为不可解（无 NaN、无伪造有限电流）。
  - 移动元件后连接保留，重新求解电流仍为 0.04A。
  - 390px 视口下 `scrollWidth == clientWidth`，无水平溢出；控制台无错误。
- 未实现项：不支持交流、电容、电感与半导体模型；灯泡亮度为耗散功率的线性映射，不含灯丝电阻随温度变化的物理过程。
