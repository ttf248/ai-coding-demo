## 运行与验证

- 入口：`index.html`，纯静态单文件（HTML/CSS/JS/SVG 内联），无后端、无 CDN、无远程资源，`file://` 直接双击打开与 HTTP 静态托管均可运行。
- 操作：上方按钮添加电池/电阻/灯泡/开关；拖动元件本体移动（连线跟随）；从端子拖出到另一端子连线（触摸设备可两次点按端子完成连线）；点选元件/导线后可在左侧面板改参数或删除（删除元件连带清除其连线）；点击开关本体切换通断。
- 求解：同一连通导线的端子归为同一电路节点（板上同色圆点）；采用改进节点分析（MNA，理想电压源与闭合开关作为 0V 电源引入电流未知量）求解；开路显示零电流；电源短路、相互冲突的理想电源、无唯一解（悬空子电路、相同电压电池并联等）给出提示，不输出 NaN 或虚假数值。
- 灯泡按固定电阻 120 Ω 简化建模，亮度 = 耗散功率 ÷ 1.2 W。
