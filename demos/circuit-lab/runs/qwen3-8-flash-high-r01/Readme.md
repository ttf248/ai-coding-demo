## 运行与复盘

- 运行方式：浏览器直接打开本目录 index.html（纯静态、离线、无 CDN）。
- 实现要点：SVG 画布上放置电池/电阻/灯泡/开关，拖本体移动（连线跟随端子引用重画）、从端子拖出或点选两点连理想导线、选中删除（级联清连线）。节点=导线与闭合开关的并查集分量；MNA 方程（电导 stamp + 每电压源约束行），高斯-约当部分主元消元；每连通分量独立取地避免浮空环路误报。灯泡亮度按 P=I²R 简化模型并标注。电池两端并入同节点→“电源短路”提示；矩阵奇异→冲突电源/无唯一解提示；不输出 NaN。开关电流用“排除自身后的端子图割集 + KCL”求得。
- 已知边界：多把闭合开关并联跨接同一割集时各自分配电流不确定（显示按计算序）；无噪声交流/半导体元件，符合任务范围。
- 验收（headless Chromium 页面内自检，`window.__circuitLab`）：12V+100/200Ω 串联 |I|=0.04A；并联支路 0.12A/0.06A、总 0.18A；开关断开→相关支路 0；短路提示；两理想电源 9V‖12V 冲突提示；1280 与 390px 均无 JS 错误、无水平溢出。
