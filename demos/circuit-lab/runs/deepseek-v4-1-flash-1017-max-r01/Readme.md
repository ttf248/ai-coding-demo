## 实现说明

- 单文件离线页面，入口 [index.html](index.html)；SVG 画布、HTML/CSS/JS 全部内联。
- 元件：理想直流电池、电阻、灯泡（固定电阻模型）、开关与理想导线；支持放置、拖动、旋转、删除、参数修改、开关通断与端子连线。
- 求解：同一导线连接的端子用并查集合并为节点，按连通分量执行节点电压法（MNA）。电池为电压源，闭合开关按 0.001Ω 近似，灯泡亮度按 `P = I²R` 映射。
- 显示：每个元件的电压、电流、功率、电流方向、节点颜色、导线路径、总电流/功率/节点数与实时测量列表。
- 异常：直接短路的电池、相互冲突的理想电源、无唯一解、开路、无电源均分别提示；错误状态不输出 NaN 或伪造有限电流。
- 交互：串联/并联预设、重置、帮助、Delete 删除、Esc 取消连线、触屏端子点选连线。

## 验证记录

- 页面内置 solver self-test，启动时在控制台输出并暴露 `window.__circuitLab.selfTest()`。
- self-test 全部通过：
  - 12V、100Ω + 200Ω 串联：电池电流 0.04A，R1 4V、R2 8V。
  - 12V、100Ω / 200Ω 并联：支路 0.12A / 0.06A，总电流 0.18A。
  - 开关断开后相关支路为 0A。
  - 电池被导线直接短接时识别为短路。
- Playwright 检查：串联/并联切换后界面状态为“仿真正常”，并联总电流显示 0.18A；无页面异常。
- 390px 无页面水平溢出；SVG 按比例缩放，端子命中区放大。

## 复盘

- 开关使用 0.001Ω 而非严格 0Ω，是为了避免理想零电阻支路让 MNA 矩阵奇异；按验收精度显示仍为 0.04/0.12/0.06/0.18，帮助面板明确说明了近似。
- 电池电流采用内部 A→B 符号；界面同时用“＋端流出/流入”的文字和箭头帮助理解。
- 未实现交流、电容、电感或半导体，符合任务边界。
