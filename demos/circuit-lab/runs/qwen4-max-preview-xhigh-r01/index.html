理想电池 / 电阻 / 开关 / 灯泡（按固定电阻建模）/ 理想导线。灯泡亮度随耗散功率变化，仅作简化演示，不是真实器件仿真。

点击端子开始连线，再点击另一端子完成（也可按住拖动）；拖动元件本体移动，连线跟随；点击开关本体切换通断；删除工具下点击元件或导线删除。Esc 取消未完成连线。

元件电压电流方向 / 功率
操作说明
  1. 选择元件工具后点击空白画布放置元件。
  2. 点击一个端子再点击另一个端子即可连线；同一连通导线归为一个电路节点。
  3. 选中电池 / 电阻 / 灯泡可修改电压或电阻；点击开关本体或属性按钮切换通断。
  4. 求解自动进行：显示各元件电压、电流与方向；开路电流为 0。
  5. 电源短路、相互冲突的理想电源、无唯一解会给出提示，不输出 NaN。
  6. 「一键重置」清空画布；预设提供可验证的串联 / 并联电路。
