## 运行方式

- 入口为本目录 `index.html`，`file://` 直接打开或 HTTP 静态托管均可，无外部依赖。
- 添加电池 / 电阻 / 开关 / 灯泡；拖动元件移动（连线跟随）；点按选中后在属性栏改电压、电阻、开关状态、旋转或删除。
- 连线：从端子拖到端子，或移动端先点端子再点端子（两段式）；连通端子经并查集归为同一电路节点。
- 每次改动立即用节点电压法（MNA）重新求解：电阻 / 灯泡按电导 1/R，理想电池为电压源支路，闭合开关建模为 0V 电压源（其电流由方程解出），断开开关直接移除支路。

- 拖动电阻后连接保留、电流不变；删除元件同时清除其连线，回路变为开路。
- 390px 无水平溢出；移动端两段式触摸连线构成回路并正确求解 0.12A。
- 桌面与移动端均无 JS 报错。

## 复盘

- 求解器为完整 MNA：未知量 = 非参考节点电压 + 每个电压源支路电流；高斯-约当消元带秩检测，区分「无解」（短路 / 冲突电源，零行非零右端）与「无唯一解」（零行零右端），两种情况都不输出伪造读数。
- 闭合开关最初按 1Ω 电阻建模会引入虚假压降，改为 0V 理想电压源后开关电流也由方程解出，串联回路中开关读数与电阻一致。
- 去掉参考地后必须压缩节点编号，否则节点行号与电源行号重叠，串联预设会误判为奇异——该 bug 由冒烟测试发现并修复。
- 「同一元件两端子互连」最初被禁止，但导线短接电池正是验收要求的短路场景，改为允许并交给求解器报告。
- 灯泡亮度按 P = I²R 对数映射到光晕不透明度，界面上明确标注这是简化模型（不模拟灯丝热惯性与非线性）。
