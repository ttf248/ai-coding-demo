# 简化电路实验台 · 任务正文 v1

实现一个完整可交互的纯静态单文件网页，入口为 index.html，HTML、CSS、JavaScript 均包含在文件内。不使用后端、CDN、远程字体、远程图片或构建步骤；通过 file:// 直接打开和 HTTP 静态托管均可运行。界面采用中文，兼容桌面鼠标和移动端触摸，390px 宽度无页面水平溢出。所有控件必须实际生效，提供清晰的操作说明、重置功能和必要的错误提示。不要仅制作界面或用固定动画冒充计算。

制作简化直流电路实验台，只包含理想直流电池、电阻、开关、按固定电阻建模的灯泡与理想导线，不包含交流、电容、电感或半导体。用户可放置、拖动、删除元件，将端子连线，修改电池电压及电阻值，切换开关。同一连通导线归为电路节点，对有唯一解的串联、并联及混合电路执行实际直流求解，显示元件电压、电流与方向。灯泡亮度随耗散功率变化，并明确这是简化模型。对开路显示零电流，对电源短路、相互冲突的理想电源及无唯一解情况显示提示，不输出 NaN 或伪造有限电流。提供串联、并联预设和一键重置；不依赖服务器。

验收：12V 电源与 100Ω、200Ω 串联时电流为 0.04A；同样电阻并联时支路电流分别为 0.12A、0.06A，总电流为 0.18A；断开开关后相关支路电流为零；移动元件保留连接；删除元件清除相关连线；短路有明确提示；触摸端子可完成连线。
