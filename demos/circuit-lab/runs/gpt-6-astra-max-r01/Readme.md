## 实现

- SVG 元件编辑、端子连线、删除、参数修改、开关切换、串并联预设；电压、电流方向及灯泡耗散功率实时更新。
- 并查集合并理想导线节点，改进节点分析加高斯消元求解；闭合开关作为零电压源保留其支路电流。支持画布缩放、复位及平移。

## 验证

- 12V / 100Ω / 200Ω 串联电流 0.04A；并联支路 0.12A、0.06A，电源总电流 0.18A。断开开关后电流为零。
- 验证拖动保留连线、删除清除连线、触摸端子连接；短路、冲突电源及非唯一解分别显示错误，不输出 NaN。

具体脚本、运行报告与截图见整轮实验报告。自动验证环境为 Windows、Node.js 22.16.0、Playwright 1.58.2 和无头 Chromium，3D 检查使用 SwiftShader。

## 边界与复盘

- 理想直流与固定电阻灯泡模型，只模拟稳态电学；不涵盖真实灯丝温度、交流或瞬态元件。
