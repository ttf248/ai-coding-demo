## 运行与复盘

**入口**：[index.html](index.html)。单文件、纯离线，可直接以 `file://` 打开，也可经本地静态服务器访问，不需要联网、CDN 或构建步骤。

**运行方式**：从元件栏放置电池、电阻、开关与灯泡；点击元件端子两两连线；右侧面板编辑电压/阻值；用「串联 / 并联 / 混联」预设快速切换；点击求解查看各元件电压、电流、功率与方向，灯泡亮度随耗散功率变化。

**实现要点**：等电位端子用并查集归并为节点，再以修正节点分析（MNA）建立矩阵并用高斯消元求解；对浮动节点加入极小对地导纳保证矩阵可解；短路、冲突理想电源与无唯一解给出明确提示而不输出 `NaN`；元件拖动与 SVG 事件监听只注册一次，避免重复绑定。

**验证记录**：串联预设总电流 0.040 A；并联预设总电流 0.180 A、两支路分别 0.120 A / 0.060 A；开关断开后全部电流为 0；短接电源时给出短路提示。以 Node `vm` + DOM stub 实跑内联脚本，并用 `node --check` 检查内联脚本语法，均通过。

**已知限制**：只覆盖直流线性电阻与理想电源，不含电容、电感与暂态过程；节点数较大时未做矩阵稀疏优化。
