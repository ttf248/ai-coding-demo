简化直流电路实验台 · DC Circuit Lab

放置元件 → 端子连线 → 求解串联 / 并联 / 混合电路。理想直流电池 + 电阻 + 开关 + 灯泡 + 理想导线，无交流、电容、电感或半导体。

放置元件

新元件会放到第一个空位，可随后拖动。

连线方式

依次点击（或触摸）两个元件的端子即可连线；再次点击同一端子取消。 点击端子后拖动到另一个端子也可以连线。连线是理想导线，会把端子合并成同一个电路节点。

操作说明

怎么用
  • 点“串联 / 并联预设”可快速得到验收电路。
  • 点元件选中，在左栏改电压 / 阻值，或切换开关。
  • 拖动元件会保留已有连线（连线跟随端子）。
  • 选中元件或导线后按“删除”，或按键盘 Delete。
  • 移动端：手指拖动元件，点端子完成连线。
计算模型与边界
  • 使用节点分析（含理想电压源的改进节点法）求解直流工作点，不是动画模拟。
  • 导线与闭合开关视为理想 0 电阻，因此同一连通导线上的端子归为同一个节点。
  • 灯泡按固定电阻建模，亮度只随耗散功率变化，不模拟灯丝温升等非线性效应。
  • 电源短路、相互冲突的理想电源或无唯一解时不给出伪造的有限电流。
  • 理想模型中不包含导线电阻、电池内阻与元件功率上限。
