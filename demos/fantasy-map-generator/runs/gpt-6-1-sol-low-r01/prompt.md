# 奇幻地图生成器 · 任务正文 v1

实现一个完整可交互的纯静态单文件网页，入口为 index.html，HTML、CSS、JavaScript 均包含在文件内。不使用后端、CDN、远程字体、远程图片或构建步骤；通过 file:// 直接打开和 HTTP 静态托管均可运行。界面采用中文，兼容桌面鼠标和移动端触摸，390px 宽度无页面水平溢出。所有控件必须实际生效，提供清晰的操作说明、重置功能和必要的错误提示。不要仅制作界面或用固定动画冒充计算。

制作手绘风格的奇幻岛屿地图生成器。提供种子输入，同一种子及参数应生成相同地图；可调整海平面和地形粗糙度。地形包含海洋、海岸、平原、森林与山脉，河流应沿地势下降流向海洋或合理的内陆水体，不能随机穿越山峰。提供升高、降低地形的画笔，编辑后更新海岸和河流。支持平移、缩放、城镇标签显示与 PNG 导出。首屏包含可操作的默认地图和图例。

验收：相同种子重生成结果一致；改变种子产生不同地图；画笔确实修改地形并联动地图；缩放后绘制坐标正确；导出图片包含当前地图；触摸操作可用。
