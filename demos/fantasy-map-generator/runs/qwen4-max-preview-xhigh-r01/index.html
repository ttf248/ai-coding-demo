奇幻地图生成器 手绘风格 · 种子化岛屿

同一种子与参数生成相同地图。河流沿地势下降流入海洋或内陆湖，不会穿越山峰。支持地形画笔、平移缩放、城镇标签与 PNG 导出。

默认地图已生成。滚轮缩放，拖动平移；切换画笔后在地图上涂抹修改地形。
触摸：单指平移 / 涂抹，双指缩放。图例与指北针绘制在画面内，导出 PNG 包含当前视图。
操作说明
  1. 输入种子点击「生成」：同一种子 + 海平面 + 粗糙度结果完全一致；「随机种子」产生新地图。
  2. 海平面控制海岸线位置；粗糙度控制地形起伏细节。
  3. 「升高 / 降低地形」画笔涂抹后，海岸、河流与城镇自动更新。
  4. 河流从高地沿最陡下降方向流动，入海或在洼地形成内陆湖。
  5. 「城镇标签」开关显示 / 隐藏城镇；「导出 PNG」下载当前画面。
  6. 「重置」恢复默认种子与参数。
