## 运行与复盘

这是一个保留前后端源码的全栈实验，不提供伪造的静态预览。`frontend/` 是 React + Vite 客户端，包含市场切换、行情表格、自选合约新增/编辑/删除、请求日志和后端不可用告警；`backend/` 是 Go Gin + GORM + PostgreSQL 服务，提供 CORS、参数校验、错误响应和请求/应答日志。
