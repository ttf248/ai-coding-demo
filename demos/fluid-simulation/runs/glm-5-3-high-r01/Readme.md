## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开即可，无外部依赖。
- 模拟：WebGL 实时求解二维 Navier-Stokes——半拉格朗日平流（速度场与染料场）、散度计算、Jacobi 压力迭代（次数可调 10–60）、梯度减除投影；不是粒子轨迹或渐隐画布。
- 控件：染料颜色（7 色盘）、注入力度、染料消散、压力迭代次数、模拟分辨率（64/128/256，重建时释放旧纹理与帧缓冲）、暂停/继续、清空染料（保留速度场）、重置参数、PNG 截图。
- 验证记录（对应任务验收项）：
  - 注入染料后画面立即变化，连续求解步进画面持续演化（无头环境用内部钩子逐步验证后已移除该钩子）。
  - 分辨率 64/128 来回切换后模拟继续正常演化，控制台无 WebGL 错误。
  - 暂停按钮在"⏸ 暂停/▶ 继续"间切换；不支持 WebGL 或浮点纹理时页面显示明确错误提示而非空白。
  - 窗口 resize 重建模拟，坐标换算以 getBoundingClientRect 归一，DPR 限制为 2。
- 实现修复记录：着色器中 uVelocity 曾误声明为 vec2（已改为 sampler2D）、顶点/片元 texel 精度不一致（片元统一 highp）、分辨率切换时单缓冲 divergence 误用双缓冲释放逻辑导致引用已删除纹理（已修复为兼容两种结构）。
