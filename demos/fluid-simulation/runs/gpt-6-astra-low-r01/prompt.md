# 彩色流体实验台 · 任务正文 v1

实现一个完整可交互的纯静态单文件网页，入口为 index.html，HTML、CSS、JavaScript 均包含在文件内。不使用后端、CDN、远程字体、远程图片或构建步骤；通过 file:// 直接打开和 HTTP 静态托管均可运行。界面采用中文，兼容桌面鼠标和移动端触摸，390px 宽度无页面水平溢出。所有控件必须实际生效，提供清晰的操作说明、重置功能和必要的错误提示。不要仅制作界面或用固定动画冒充计算。

制作彩色流体实验台。使用 WebGL 实时计算二维速度场和染料场，包含平流、散度、压力迭代和速度投影，禁止仅用粒子轨迹或渐隐画布替代流体模拟。鼠标或手指拖动时注入颜色和动量，形成扩散、卷曲与混色。提供染料颜色、注入力度、染料消散、压力迭代次数、模拟分辨率等控制，以及暂停、继续、清空、重置参数和 PNG 截图。界面在深色背景下清晰可读。限制设备像素比和分辨率，正确释放重建的 GPU 资源。检查 WebGL 及所需纹理格式支持，无法运行时给出明确提示；窗口改变大小后模拟与触摸坐标仍正确。

验收：拖动方向影响流动；染料与速度随时间演化；参数变化影响计算；暂停后画面停止演化；清空移除已有流体内容；截图可下载；不支持 WebGL 时不出现空白页面；移动端运行且无水平溢出。
