操作说明

  1. 在画布上按住拖动（鼠标或手指，支持多指）注入染料和动量，拖动方向决定流动方向。
  2. 调节染料颜色、力度、半径与各项模拟参数，变化会即时作用于计算。
  3. “暂停”冻结演化；“清空”移除全部染料与速度；“重置参数”恢复默认设置；“截图 PNG”下载当前画面。
  4. 快捷键：空格 暂停/继续，C 清空，R 随机喷溅。

每一帧的计算

  1. 注入：在指针位置叠加高斯形状的速度与染料。
  2. 涡度：计算速度场旋度，并施加涡度约束力，保留卷曲细节。
  3. 散度：计算速度场散度 ∇·u。
  4. 压力：以 Jacobi 迭代求解泊松方程 ∇²p = ∇·u（次数可调）。
  5. 投影：u ← u − ∇p，得到无散速度场。
  6. 平流：半拉格朗日法沿速度回溯，分别平流速度与染料，并按消散率衰减。
