操作说明
  1. 在画布上拖动：沿拖动方向注入动量，同时注入所选颜色的染料。
  2. 注入力度控制速度 splat 强度；染料消散控制颜色衰减快慢。
  3. 压力迭代次数越高，不可压缩投影越精确（性能开销越大）。
  4. 模拟分辨率改变速度 / 染料网格尺寸，会重建 GPU 资源。
  5. 暂停 / 继续控制演化；清空归零所有场；重置参数恢复默认。
