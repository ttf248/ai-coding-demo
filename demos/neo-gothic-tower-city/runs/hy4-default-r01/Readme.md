## 运行与复盘

**入口**：[index.html](index.html)。单文件、纯离线，可直接以 `file://` 打开，无 CDN、无远程贴图、无构建步骤。

**运行方式**：鼠标拖动旋转/平移视角、滚轮缩放，键盘或按钮漫游塔楼城市；可切换昼夜与天气氛围。

**实现要点**：按原文「库缺漏先标示待确认并继续」的约定，环境无可用离线 3D 库，因此用 Canvas 2D 手写透视投影、面排序（画家算法）、背面剔除、方向光着色与距离雾，程序化生成塔身、飞扶壁、拱窗、尖顶与街区；`archWindow()` 按 `±x / ±z` 四个面生成坐标；渲染加入视锥裁剪，跳过完全离屏的面。页面内保留「待确认」标注说明 3D 库缺漏。

**验证记录**：内联脚本语法检查通过；四面拱窗坐标与视锥裁剪经复核后修正；页面标注与实现一致。

**已知限制**：这是自定义 2D 投影渲染而非真实 WebGL 场景；海浪为顶点波动、火焰与尘埃为屏幕空间粒子，均为简化实现，已在页面注明；无真实阴影、PBR 材质与遮挡查询。
