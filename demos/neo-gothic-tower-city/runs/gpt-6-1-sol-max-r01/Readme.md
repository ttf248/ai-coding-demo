## 场景

1 个单位为 1 米。35 座塔楼、132 米主塔、教堂中殿、尖拱、玫瑰窗、飞扶壁、屋顶尖塔、街道、环岛海堤、桥与码头。海浪、火焰、星空均为程序粒子或 shader；建筑按材质合并批渲染。Three.js r160 内嵌于单文件，许可见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 操作

- 拖动环视，滚轮缩放，闲置环绕。
- 环城、街巷、鸟瞰三个模式；海港、教堂、尖塔群三个观景点。
- 街巷：WASD / 方向键，Shift 加速；手机有方向按钮。拖动或鼠标锁定调整朝向，Esc 释放。
- 四套光景，暂停时间，H 隐藏界面，保存 PNG 画面。
- 走路固定人眼高度；建筑矩形与岛屿边界阻挡移动。不是通用物理引擎。

## 运行与复盘

[index.html](index.html) 可直接打开或 HTTP 访问；已在阻断全部 HTTP 请求的 file:// 测试中渲染，390px 无溢出。WebGL 不可用时显示『待确认』提示。修复内嵌库替换时的美元符号展开、初始街巷朝向及帧率统计；静态几何合并后，一次采样绘制次数从 548 降至 18。该数字为本机一次观测，不能当成设备间公平性能结论；软件渲染环境未证明稳定 60 FPS。
