## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开即可。零依赖：不引用任何 CDN 或外部库，全部渲染由自研 WebGL 管线完成，因此完全离线可用。任务允许对环境缺漏标"待确认"，本轮未遇到需标注的缺漏。
- 场景：程序化生成的 37 座新哥特式塔楼（主体、腰线、上层塔身、四面锥顶、角部小尖塔）环绕中央大教堂；每座塔带自发光拱窗（暖黄光点）、石砌地面与环形海面。天空为渐变穹顶 + 程序化星空 + 月亮，火焰余烬（420）与海面浪花微光（380）两套加色混合粒子持续演化，海面顶点做三重正弦波浪。
- 相机：闲置时自动环绕漫游，拖动环视（yaw/pitch），滚轮缩放；昼夜由右上滑杆控制（影响雾色、窗光强度、波浪振幅与星空/月亮）。
- 验证记录：同相机角度两次渲染画面随粒子演化而变化；改变相机角度画面明显不同；昼夜滑杆切换后画面色调改变；控制台无任何 WebGL 错误。验证借助临时渲染钩子完成后已移除。
- 实现修复记录：粒子系统首版每帧创建临时 GL buffer，已改为按类型预分配持久 buffer + bufferSubData 更新；水面顶点波曾误乘整体 y 缩放，已改为纯加性波幅。
