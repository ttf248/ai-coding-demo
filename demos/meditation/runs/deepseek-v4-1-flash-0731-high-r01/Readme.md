## 产品与设计说明

- **用户与场景**：睡前难入睡、白天注意力涣散、通勤焦虑的都市用户。真实诉求不是「学冥想」，而是**在具体时刻被立刻接住**。
- **功能规划**（产品经理视角）：
  1. 场景化入口——打开就是「今晚想做什么」，四张卡片对应减压冥想 / 呼吸练习 / 睡眠故事 / 身体扫描，不需要理解术语。
  2. 最低门槛开始——3 分钟起步，免注册可试听 3 节。
  3. 引导可跟随——呼吸练习用 4-7-8 节奏配合可视线圈与倒计时，播放页用圆环表达进度。
  4. 睡眠闭环——睡眠定时、睡前清单、次日入睡反馈。
  5. 坚持可见——连续天数、里程碑、行为洞察（如「你的练习集中在 22:00-23:00，与入睡时间高度重合」）。
- **信息架构**：底部四个一级入口（首页 / 探索 / 统计 / 我的），播放页与呼吸练习页为全屏二级页面。
- **设计规范**（设计师视角）：以深夜色 `#131a30` 为底，搭配湖蓝 `#8fd6e8`、丁香紫 `#b3a4f5`、暖沙 `#e8c9a0` 三条渐变；深夜场景下白色文字降低到 60%~90% 不透明度以减少眩光；圆环、呼吸光晕与波形均以动效表达节奏；正文 375pt 基准。
