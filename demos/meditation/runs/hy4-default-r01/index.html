PRODUCT & UI/UX SPEC · V1.0

静屿 · 冥想 iOS App 原型

从真实场景出发：通勤后的 5 分钟降压、入睡前的呼吸与故事、通勤碎片里的短练习、以及坚持不下去时需要的温和回顾。不做打卡焦虑，只降低开始的成本。

用户场景与需求

① 睡前脑子停不下来 → 睡眠故事 / 白噪音；② 会议前心跳快 → 3 分钟呼吸；③ 想系统练习 → 7 天入门课程；④ 三天没打开 → 不带责备的回顾而非红点催促。

产品信息架构

今日 / 探索 / 练习 / 我的 四个 Tab。核心链路：首页推荐 → 课程或单次练习 → 播放器（含计时、音景、后台播放）→ 完成页 → 沉淀到统计。

视觉与交互规范

深靛蓝夜色 + 极光紫 / 薄荷绿渐变；毛玻璃卡片、柔光圆晕、低对比文字层级；375px iPhone 基准，主操作在拇指热区；动效缓慢（≥500ms），避免闪烁。
