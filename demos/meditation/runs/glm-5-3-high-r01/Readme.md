## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开。需联网（Tailwind CDN、FontAwesome CDN、Unsplash 图片）。
- 实现方式：按任务正文要求，全部页面在同一 HTML 文件中展示；样式全部由 Tailwind CDN 工具类完成，无自定义 style 块；图片全部使用 Unsplash；图标使用 FontAwesome 6 开源图标库。
- 产品视角功能规划（模拟真实用户的一天场景：清晨唤醒 → 白天减压 → 睡前助眠 → 长期回顾），共 8 个核心界面：
  1. **欢迎页**：呼吸光圈动效、价值主张轮播、首次冥想 CTA。
  2. **今日首页**：当日推荐大卡、按需求场景分类入口（快速平静/缓解焦虑/入睡引导）、本周旅程（安眠七日）、大师课程横排。
  3. **课程库**：搜索与筛选、课程列表（白噪音/呼吸引导/正念/场景音）、会员引导卡。
  4. **呼吸引导**：4-7-8 呼吸法跟随光圈（吸气/屏息节奏提示）、轮次进度、音量与收藏控制。
  5. **冥想播放**：全屏沉浸背景、导师封面、播放进度、背景音混合（海浪/雨声/颂钵）。
  6. **睡前模式**：就寝倒计时、整夜助眠音、睡前流程开关（勿扰/睡眠故事/睡眠记录）。
  7. **进度统计**：累计时长与月目标圆环、本周练习柱状图、连续天数/次数/安睡之夜、健康洞察卡。
  8. **我的**：账户与会员状态、练习提醒/勿扰时段/伙伴房/健康联动/隐私设置。
- 设计语言：深靛蓝夜空基调 + 青绿（teal）与靛紫点缀的宁静配色，大圆角卡片、玻璃感导航、呼吸光圈（animate-ping/pulse）贯穿核心场景。
- 验证记录：8 屏均为 375px 宽，14 张 Unsplash 图片全部加载无破图（首版 1 张图源失效已替换），78 个 FontAwesome 图标实际渲染（computed font-family 为 "Font Awesome 6 Free"），无横向滚动条，控制台仅 Tailwind CDN 生产环境提示（CDN 方案为任务正文要求）。
