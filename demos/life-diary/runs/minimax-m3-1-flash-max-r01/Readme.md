## 实现说明

单文件 `index.html`，Tailwind CSS 通过 CDN 引入，图片使用 Unsplash 源，全部 7 个原型页面横向排列在同一页面中，每个页面用 375px 宽的手机外框独立呈现（相互不影响），可直接作为开发参考。

### 页面规划（产品经理视角）

| 页面 | 作用 | 关键内容 |
|---|---|---|
| 01 今日概览 | 每日入口 | 情绪快捷打卡、AI 预填、连续记录天数、本周平均、最近片段 |
| 02 记录情绪 | 核心写入流 | 情绪选择、影响因素标签多选、自由文本、AI 提示、保存 |
| 03 日记时间线 | 回顾 | 带图条目、情绪标签、AI 摘要、按条件筛选 |
| 04 情绪趋势 | 数据洞察 | 平均心情折线 + 柱状背景、情绪构成占比、AI 洞察卡 |
| 05 AI 洞察 | 智能总结 | 本周小结、压力来源排行、可执行建议、关键词云 |
| 06 生活片段 | 记忆聚合 | 按主题自动聚类的相册片段与平均心情 |
| 07 个人中心 | 设置 | 头像与统计、提醒、AI 周报开关、隐私、导出、外观 |

### 交互

- 情绪选择（今日概览 / 记录页）实时更新选中状态与文案。
- 影响因素标签可多选，选中后变为品牌色。
- 日记时间线支持「全部 / 带图 / 有 AI 摘要」筛选。
- 情绪趋势支持周 / 月 / 季切换，SVG 折线与柱状背景随之重绘，X 轴标签同步变化。
- 底部标签栏在 7 个页面中保持一致的导航结构。
