# 心语日记 - 快速使用指南

## 🚀 快速开始

### 打开应用
1. 在浏览器地址栏输入文件路径或直接拖拽 `index.html` 到浏览器
2. 应用会自动加载，显示 iPhone 风格的界面

### 系统要求
- ✅ 现代浏览器（Chrome、Firefox、Safari、Edge）
- ✅ 启用 JavaScript
- ✅ 支持 localStorage
- ✅ 网络连接（用于加载 Tailwind CSS 和 Font Awesome）

### 2️⃣ 日记编写 (Diary)
**功能：** 记录情绪和日记内容
- 📅 自动记录当前日期和时间
- 😊 5种情绪选择（难过、生气、平静、开心、兴奋）
- 📈 情绪强度滑块（1-10）
- 🏷️ 活动标签（工作、运动、学习、娱乐、社交、休息）

**操作步骤：**
1. 点击下方导航栏的"日记"图标
2. 选择今天的情绪（点击情绪emoji）
3. 调节情绪强度（左右滑动滑块）
4. 选择今天的活动（点击标签切换）
5. 在文本框输入日记内容
6. 点击"保存日记"按钮
7. 成功保存后自动返回首页

**提示：**
- 所有日记会自动保存到浏览器本地
- 刷新页面数据不会丢失
- 可以多次保存不同时间的记录

## 💾 数据管理

### 数据存储位置
- 所有日记数据存储在浏览器的 localStorage 中
- 数据持久化，不会因为刷新页面而丢失

### 导出数据
1. 进入设置页面
2. 点击"导出数据"按钮
3. 会下载一个 `diaries-backup.json` 文件
4. 这个文件包含所有你的日记记录

### 导入数据
- 当前版本不支持直接导入，但可以通过浏览器开发者工具导入：
  1. 打开浏览器开发者工具（F12）
  2. 进入 Console 选项卡
  3. 输入：`localStorage.setItem('diaries', '[JSON数据]')`

### 清除数据
- 进入设置页面，点击"重置应用"
- **警告：** 此操作无法撤销！

## 🎯 使用建议

### 建立记录习惯
1. **固定时间** - 每天相同时间记录，如晚上10点
2. **坚持记录** - 连续记录对趋势分析很重要
3. **详细描述** - 写下具体的事件和感受

### 充分利用情绪强度
- 1-3：轻微情绪
- 4-6：中等情绪
- 7-10：强烈情绪

### 活动标签的作用
- 帮助识别哪些活动影响情绪
- 例如：运动后通常更开心
- 工作压力大时容易感到疲惫

### 分析你的数据
- 每周查看趋势，识别情绪模式
- 找出能改善心情的活动
- 建立积极的生活习惯

## ⚡ 快捷操作

### 键盘快捷键
- 当前版本暂无快捷键支持

### 常见问题

**Q: 数据会保存多久？**
A: 只要浏览器 localStorage 不被清除，数据会一直保存

**Q: 能在不同设备间同步吗？**
A: 当前版本不支持，所有数据仅在本设备本浏览器中

**Q: 能删除某条日记吗？**
A: 当前版本暂不支持，可以通过"重置应用"清除所有数据

**Q: 没有网络连接能使用吗？**
A: 可以，但初次加载需要网络。之后 CSS 和图标库会被缓存

**Q: 如何修改已保存的日记？**
A: 当前版本暂不支持编辑，需要重新记录
