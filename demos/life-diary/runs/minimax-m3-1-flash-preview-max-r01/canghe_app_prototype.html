PROTOTYPE · V1

沧河 · AI 情绪日记与生活助手

面向 18–35 岁、习惯记录生活的城市用户。产品主线是「情绪速记 → AI 复盘 → 生活干预」： 每天一次轻量情绪打卡，AI 在夜间生成情绪复盘与生活建议，再把建议落成可执行的习惯与待办。 以下 10 个界面覆盖从首次启动到长期使用的完整链路，全部基于 iPhone 标准尺寸 375 × 812 设计，组件可直接交付开发。

设计基准 375px Tailwind CSS FontAwesome 6.5 Unsplash 10 个界面 4 个一级 Tab

交付说明

信息架构

四个一级 Tab：首页（情绪速记 + AI 复盘 + 生活片段）、日记（时间线 / 详情 / 趋势）、生活（习惯打卡 + 待办）、我的（成就 / 隐私 / 通用）。

设计令牌

主色 #6C5FD6，辅助 #FF7A8A，圆角 16 / 20 / 26px， 卡片阴影 0 10px 30px -14px rgba(27,26,42,.22)。

开发对接

全部使用 Tailwind 原子类（Play CDN），无行内 style 与自定义 CSS 动画，组件可直接映射为 React / Vue 组件；图标统一使用 FontAwesome 6.5，图片使用 Unsplash CDN。

移动端适配

以 375 × 812 为基准；顶部 44px 状态区、底部 78px TabBar（含 20px 安全区）， 内容区使用 `no-scrollbar` 隐藏滚动条但保留惯性滚动。
