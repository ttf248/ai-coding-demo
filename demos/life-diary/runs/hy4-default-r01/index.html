PRODUCT SPEC · V1.0

沧禾 · AI 情绪日记与生活助手

以「低负担记录 → 温和解读 → 可执行的小建议」为主线。用一次点选完成情绪打卡，用 AI 把零散记录整理成可回顾的生活叙事，避免把心理健康产品做成数据考核。

01 · 功能与信息架构

今日首页 / 情绪速记 / AI 陪伴对话 / 心情日历与趋势 / 生活片段时间线 / 周期洞察报告 / 自助练习 / 个人中心与隐私设置。底部四 Tab：今日、回顾、AI 助手、我的。

02 · 目标场景

通勤路上 30 秒打卡；睡前 3 分钟回顾；情绪波动时与 AI 对话；月末查看趋势与触发因素；需要时直接跳到呼吸练习。所有页面按 iPhone 375px 基准设计，拇指热区集中在下半屏。

03 · UI/UX 规范

主色鼠尾草绿 #7c9c83，辅以藕紫 / 陶土 / 鹅黄表示情绪；大圆角 20–28px、轻玻璃拟态、留白优先；正文 13–15px，标题 20–26px；状态色不用于评判用户情绪。

375px 基准 Tailwind CSS FontAwesome 图标 Unsplash 图片 玻璃拟态 / 大圆角 可直接拆解为组件
沧禾 App 原型图 · 全部页面在同一 HTML 中展示 · 每屏为独立的 375px 移动端画布，点击心情或底部 Tab 可查看局部交互反馈。
