运行条件与识别说明

使用 Three.js Points 与 BufferGeometry；MediaPipe Hand Landmarker 在浏览器中运行。未请求摄像头时不会读取视频。手指伸展由指尖相对手腕距离判定，识别受姿态、光线与遮挡影响。捏合采用手掌尺度归一化的距离。摄像头需要 HTTPS 或 localhost 安全环境；拒绝权限后仍可使用鼠标、触控或“全部还原”。上传图片与视频不发往后端。

图片按最长边 320px 缩小后采样，透明像素略过；初始散布位置独立于目标位置。重建会释放旧几何资源。关闭摄像头会停止全部视频轨道，离开页面会释放模型、视频与 GPU 资源。
