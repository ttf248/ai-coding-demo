## 运行与操作

通过仓库静态服务器打开 `index.html`，摄像头授权使用本机 HTTP 或 HTTPS。粒子渲染和手势模型依赖网络。

上传本地图片并选择采样密度，点击还原、打散，或按住画布拖动局部力场。主动开启摄像头后，张开手掌吸引局部粒子，握拳暂停手势吸引。

## 实现与复盘

Canvas API 读取图片像素，Three.js 点材质渲染粒子。MediaPipe 手部关键点映射到镜像摄像头与画布坐标，局部还原随手掌位置和距离变化。

图片和摄像头画面由浏览器本地处理，模型从 CDN 加载。没有实物摄像头的环境仍可使用指针和按钮。

Chromium 的虚拟视频源验收了摄像头和 MediaPipe 的启动、停止与释放，真实手势识别仍待实机验证。
