# 图片粒子化与手势还原（DeepSeek-V4.1-Flash · high · r01）

单文件网页，直接打开 [index.html](index.html) 即可运行。**需要联网**：通过 import map 加载 Three.js r160，并从 CDN 动态加载 MediaPipe Tasks Vision 的手部模型。无后端、无构建步骤。

## 原始提示词

见 [完整原始输入](prompt.md)；任务正文与 [v1 任务正文](../../prompts/v1/prompt.md) 逐字一致（该正文含中英双语同一份需求）。

## 实现要点

- **流程**：`<input type="file">` 上传本地图片 → 离屏 Canvas 取像素 → 按可调采样间隔把每个采样点变成一个 Three.js `Points` 粒子，并记录其原图位置与颜色。
- 初始状态是**随机球状分布的飘散粒子流**，不是原图。粒子围绕各自的「漂浮基准位置」做带阻尼的振荡，因此粒子云始终有界，不会越飘越远。
- **手势**：MediaPipe `HandLandmarker`（VIDEO 模式）逐帧检测手部关键点；以腕到指尖与腕到指节的距离比判断「张开手掌」（≥3 指伸展）还是「握拳」，掌心取 landmark 9。
- **力场**：手指移动时，以掌心为圆心、可调半径的吸引区域跟随移动；场内粒子被强吸引，场外保留较弱的全局吸引——挥动手掌能明显看到局部被"吸"回原图，松开手掌（握拳）则粒子重新散开。
- 内置示例图由代码用 Canvas 绘制（星云 + 环形 + 五角星 + 文字），因此**不依赖任何外部图片资源**即可演示完整流程。
- 摄像头不可用（无 `getUserMedia`、拒绝授权）或 MediaPipe 模型加载失败时，都会给出明确的中文提示，并回退到**鼠标 / 触摸手势**：按住画面等同于「张开手掌」，面板上同步显示按压状态。

## 运行与复盘

- 运行方式：联网状态下用浏览器直接打开本目录 `index.html`；摄像头手势需要 `https` 或 `localhost` 等安全上下文，`file://` 下部分浏览器会拒绝摄像头。
- 复盘：首轮生成后经自查修正多处，均为首轮内部问题，`changes` 为空。关键一处：飘散分支原先只叠加正弦速度、没有任何回复力，粒子会无限漂移（实测 5 秒后单颗粒子已漂到 5 个单位外），导致还原几乎不可见（3 秒仅 6%）；改为围绕「漂浮基准位置」的带阻尼振荡后，还原稳定在 3~4 秒内到达 100%。另外两处：力场半径最初只有视口宽度的约四分之一且场外完全没有吸引，按住手掌几乎无效，改为场内强吸引 + 场外弱吸引并把光环半径与真实力场对齐；「还原图片」按钮的强制吸引标志被指针分支覆盖而失效。最后把指针模式的按压状态显示到面板上，用户能确认手势已被识别。
