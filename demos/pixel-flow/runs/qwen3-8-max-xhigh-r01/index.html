手势说明：张开手掌 = 激活还原力场（粒子加速回位）；握拳 = 暂停还原（粒子继续飘散）；手的位置 = 力场中心（力场内粒子额外加速）。 降级模式：摄像头不可用、MediaPipe 加载失败或处于 iframe 等无摄像头授权环境时，自动切换为鼠标 / 触摸力场（按住画布 = 激活还原）。 技术栈：Vanilla JS + Three.js（粒子渲染）+ MediaPipe Hands（手部关键点）+ Canvas API（像素提取）；力场为弹簧-阻尼物理，非固定动画。
