### 🚀 使用方式

#### 安装和运行
```bash
# 进入项目目录
cd demos/pixel-flow/runs/claude-haiku-45-mid-r01/

# 安装依赖
npm install
# 安装内容:
# - three@^r128
# - @mediapipe/tasks-vision@^0.10.0
# - vite@^4.4.0

# 开发模式
npm run dev
# 访问: http://localhost:5173

# 生产构建
npm run build
# 输出: dist/ 目录

# 预览生产版本
npm run preview
```

#### 使用流程
1. 打开 http://localhost:5173
2. 上传一张图片
3. 允许摄像头访问
4. 打开手掌，看粒子被吸引到手部
5. 关闭摄像头或点击"Reset Particles"散开粒子
6. 调整粒子数量获得最佳视觉效果
