## 运行与复盘

- 入口：本目录 `index.html`，浏览器直接打开。需联网（Three.js r160 与 MediaPipe tasks-vision 均走 jsdelivr CDN，手势模型走 Google 存储）。
- 粒子化：上传任意图片（或使用内置渐变演示图），按采样密度（4000/12000/22000 目标）提取非透明像素为 THREE.Points 粒子，颜色取自原图并做伽马压暗，最多 24000 粒子。
- 飘散与还原：粒子带正弦飘散流场持续漂浮；"飘散"按钮注入随机速度，"还原"按钮激活全局吸引场，全部粒子以弹簧力回归原图位置，进入原位半径后直接吸附并完全静止（10800 粒子实测 max 误差收敛到 0）。
- 手势：摄像头模式经 MediaPipe HandLandarker（21 关键点）识别张开手掌（激活手掌位置吸引场，附近粒子加速归位）与握拳（暂停吸引），掌心位置映射到场景平面；演示模式用鼠标左键模拟手掌、右键模拟握拳，右键已禁用菜单。
- 控件：采样密度三档、还原速度 0.25x–2.5x、吸引场半径滑杆，实时生效。
- 验证记录：演示图加载 10800 粒子、飘散→还原→再飘散全流程通过（还原后全体粒子精确吸附原位、静止无抖动），演示模式吸引场坐标换算正确，控制台无错误。
- 修复记录：初版在还原激活时仍对粒子注入飘散流场，导致与弹簧力形成约 2 个单位的持续振荡、无法完全静止；改为吸引中的粒子不注入流场并在近原位时直接吸附。另修复"还原"状态持续时点击"飘散"无效的问题（飘散时取消全局吸引）。
