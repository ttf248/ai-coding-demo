读数口径

· 还原进度 是所有粒子 progress 的平均值（0 = 完全飘散，1 = 归位），不是"完成了百分之多少的工作量"。 力场内的粒子 drive 更强，所以进度条爬升是空间上不均匀的。

· 采样：格 / 保留 / 跳过 / 截断 分别指遍历的网格数、被采用的粒子数、因透明或过暗被跳过的格数、 以及因超过上限 24000 而被丢掉的格数。截断不为 0 说明画面被裁过，采样间距调大可以装下更多。

· 缓冲 是六个 Float32Array 的真实占用（positions / targets / colors / offsets 各 3×MAX，seeds 与 progress 各 MAX）。

· 当前手势 后面的两个数字是判定依据：指尖到掌心的平均距离与拇指-食指距离， 分别与 0.085 / 0.045 / 0.16 三个阈值比较后得出结论。
